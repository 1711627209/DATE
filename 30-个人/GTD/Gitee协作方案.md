# Gitee 协作方案 — 与学弟的沟通与项目管理

> **目标**：用 Gitee 当"你 + 学弟"的协作中枢，告别微信传文件，用 Issue 做任务、里程碑做阶段、Wiki 放沟通记录。
> **原则**：沟通库用**私有**（只有你俩能看），剪辑成品走网盘。

---

## 一、为什么用 Gitee 而不是微信传文件

| 微信传文件 | Gitee 协作 |
|-----------|-----------|
| 文件发来发去，版本乱 | 一个仓库，永远是最新版 |
| 任务靠口头/截图，漏掉 | Issue 列任务，谁做、做到哪、一目了然 |
| 进度看不到 | 里程碑看阶段进度 |
| 沟通记录沉在聊天里 | Wiki/文件归档，随时翻 |

---

## 二、方案目录结构（沟通库长什么样）

```
communication/（沟通库，私有）
├── README.md          ← 库说明：这库是干嘛的、怎么用
├── 00-任务/           ← Issue 在这里（见第五节）
├── 01-沟通纪要/        ← 每次沟通的纪要文件
│   └── 2026-08-21-第一次对接.md
├── 02-项目进度/        ← 每周/每阶段进度报告
├── 03-待办交接/        ← 孙超交代给学弟的活 + 交付标准
└── 04-规范/            ← SOP、协议、话术模板（只放链接或脱敏版）
```

## 三、学弟的 Getting Started（第一天照做）

### 第 1 步：注册 Gitee 账号
1. 打开 https://gitee.com
2. 用手机号/邮箱注册
3. 把用户名告诉孙超

### 第 2 步：被邀请进库
- 孙超在仓库「设置 → 成员管理」里，把你的用户名加为**协作者**

### 第 3 步：认领第一个任务
- 打开仓库的「Issue」页
- 找到分配给你的 Issue
- 评论区回复「收到，预计 X 天完成」

### 第 4 步：每天更新进度
- 每天结束，在你负责的 Issue 下评论一句：
  - 今天做了什么
  - 卡在哪
  - 明天做什么

## 四、日常协作规则（关键）

| 场景 | 怎么做 |
|------|--------|
| 孙超交代任务 | 孙超开一个 Issue，标题=任务，正文=要求+交付标准 |
| 学弟领任务 | 在 Issue 下回复"收到" |
| 学弟交活 | 把成果放对应目录，在 Issue 下回复"完成" |
| 学弟卡住 | 在 Issue 下 @孙超 提问 |
| 每周复盘 | 里程碑下看本周完成了几件事 |

---

## 五、用 Issue 做项目管理（核心）

**Issue = 任务**。每个任务一个 Issue：

```
标题：[任务] 剪辑 003 口播视频
正文：
- 要求：两天一个，3分钟，剪映
- 交付标准：成片 + 封面
- 截止：8月23日
- 负责人：学弟
```

**里程碑 = 阶段**。对应分阶段交付：

| 里程碑 | 对应阶段 |
|--------|---------|
| 阶段1 测试期 | 剪辑、排版、发布 |
| 阶段2 上手期 | 搜索整理、猎头表格 |
| 阶段3 深入期 | 课程辅助、网站建设 |

## 七、边界（安全）

- **沟通库私有**，别把链接发到任何公开地方
- **协议、话术、分成等敏感内容**，不放仓库，或只放脱敏版
- **剪辑成品走网盘**（百度网盘），不进 Gitee
- **账号密码**：孙超保留主账号，学弟只有协作者权限
