- 点右上角「注册」，用手机号或邮箱注册，设置密码

## 第 2 步：生成 SSH 密钥

- 引导我打开电脑终端（Windows 用 PowerShell 或 Git Bash，Mac 用终端）
- 运行命令生成密钥（如果还没生成过）：
  ```
  ssh-keygen -t ed25519 -C "我的邮箱"
  ```
- 一路按回车（默认路径即可，不需要设密码）
- 然后查看公钥：
  ```
  cat ~/.ssh/id_ed25519.pub
  ```
- 让我把公钥**完整复制**下来（`ssh-ed25519` 开头的一整串）
