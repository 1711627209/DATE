## 🔴 职业框架（改完简历后优先）

### 1. CDT / PDT 体系（华为 IPD）
- **是什么**：产品经理分两种——CDT（市场立项/找需求/出 charter）+ PDT（落地执行/推量产）
- **为什么重要**：我确认自己喜欢 CDT 方向。面试自我介绍时这就是定位锚点
- **行动**：搜"华为 IPD CDT charter"，看公开资料，学框架
- **来源**：姚凯 6/25

### 2. 立项文档 ≠ PRD
- **是什么**：立项文档（告诉团队"做什么/长什么样"）→ 版本规划 → 需求池 → N个PRD → 评审 → 开发
- **为什么重要**：搞清楚了自己写的5线雷达属于哪一阶段。面试不会再被问倒
- **行动**：找一份标准的立项文档模板 + PRD 模板做对比
- **来源**：姚凯 6/25

### 3. 纽尔合作 = CDT 实战
- **是什么**：胡华缺产品定义 → 我做需求调研 → 他们评价可行就开发 → 分润
- **为什么重要**：这是求职时可以讲的 CDT 案例："帮一家100+研发团队的公司做了前端产品立项"
- **行动**：写纽尔报告时，有意识地用 CDT/charter 的方法论框架
- **来源**：姚凯 6/25 帮我的判断

## 🟡 商业模式（有空深挖）

### 4. 李工 FDE 商业模型
- **核心逻辑**：接客户（10万）→ 自己出方案+架构 → coding 外包（猪八戒撒单/6-7万）→ 自己验收交付 → 赚差价
- **关键原则**：客户+代码是资产，coding 是最不值钱的环节
- **为什么重要**：给 FDE 一个不像外包一样累死的答案
- **行动**：下次跟李工聊问他猪八戒撒单的具体操作细节
- **来源**：李工 6/26

### 5. Token 中转商业逻辑
- **核心数据**：Pro 号池拿货1-2折 → 分销至少20%利润才有动力 → 4台服务器100+并发
- **风险**：政策变化、号被封、数据安全
- **为什么重要**：我自己买中转 API，但不懂上游。李工客户需要 token，Sandy 需要渠道 → 可能撮合
- **行动**：跟 Sandy 要个试用链接，体验一下
- **来源**：Sandy 搭档 6/26

### 6. 企业服务要点
- **珠三角老板画像**：初中/高中毕业，年利润几百万，"装小龙虾收200考虑半天"
- **关键原则**：企业认 SOP 不认 AI → 先问"你们有 SOP 吗" → 有就能做
- **为什么重要**：以后跟企业聊的开门问题
- **行动**：记在脑子里，下次跟企业聊直接用
- **来源**：李工 6/26

### 7. 知识付费参考：易慧（HappyCoding）
- **是什么**：推特/B站 AI 编程教学，卖课699元/人，一天收入上万

## 🟢 案例研究（碎片时间看）

### 8. Plaud.AI
- **是什么**：贴在手机背面的AI录音硬件，营收1亿美金/年，北美+欧洲第一
- **核心卖点**：自动识别会议→录音→转写，功能上飞书都有，但他们只做海外避开国内卷
- **为什么重要**：智能影像/硬件产品经理必研究案例——需求精准+硬件极简+市场选择
- **行动**：搜 Plaud.AI 的产品定位、定价、用户画像、为什么成功
- **来源**：李工 6/26

### 9. WorkBuddy
- **是什么**：AI Agent 工作助手，对不会编程的人特别好用，"你只要说需求，它推理补充然后做"
- **为什么重要**：李工说"老板不认模型只认结果"，WorkBuddy 是最接近这个逻辑的产品
- **行动**：下载试用 WorkBuddy，理解它的产品逻辑
- **来源**：李工 6/26

### 10. AI 工坊（杭州）
- **是什么**：4个联创全员兼职，2年做到杭州第一的 AI 社区。
- **模式**：小酒馆（C端99元含餐）→ demo秀（每场5个创始人）→ 政府合作（一半比例）
- **为什么重要**：我做社群可以参考的运营模型
- **行动**：搜"杭州 AI 工坊"，关注他们的活动形式和内容
- **来源**：云初 6/26
