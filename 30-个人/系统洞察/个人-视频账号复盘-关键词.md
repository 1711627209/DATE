## 自媒体战略 / 平台机制

🧷 **[敏锐关键词] 小红书封面删除疑似存在 bug**
是什么：用户复盘时提到「小红书封面删除，它是有 bug 的吗？」，怀疑小红书删除封面这个功能是坏的。
为什么值得注意：打破「平台功能默认可靠」的假设——平台机制不是拿来即信，运营者要亲手验证，功能 bug 会卡住封面更新链路。
能链接到：与「定时发布不自动配图」同属平台机制坑；封面工作流化时要把平台 bug 兜底考虑进去。

🧷 **[敏锐关键词] 抖音自带进度条 5 分钟不显示章节变化**
是什么：抖音视频进度条等了 5 分钟都不显示章节变化，所以用户认为要自己加进度条/章节，且认为进度条比小红书自带进度条好多了。
为什么值得注意：打破「平台自带进度条够用」的认知——口播长视频的章节分段平台不会自动识别展示，要靠创作者主动埋章节，观众才看得到进度。
能链接到：长口播内容要主动设计章节结构；抖音 vs 小红书在进度/章节机制上的平台差异。

🧷 **[敏锐关键词] 低角度仰拍 = 说教感，日评要平视亲切**
是什么：机位从低到高拍会形成仰视视角，观众观感是「像老师一样」居高临下在讲课，而拍日评/口语内容需要亲切感，所以要平视拍摄。
为什么值得注意：打破「内容好就行、机位无所谓」的认知——拍摄机位本身在传递情绪和身份态度，是内容的隐形部分，选错机位 = 选错人设。
能链接到：与「拍日评一定要亲切一点」的账号定位直接绑定；机位是拍摄复盘三大件（背景/视角/音画）之一。

🧷 **[敏锐关键词] 定时发布不自动配图且不可回看**
是什么：定时发布后创作者没法在发布前回看成品，平台也不会自动给配个图，导致封面和内容质量出问题时无法补救。
为什么值得注意：打破「定时发布 = 省心自动化」的认知——定时发布牺牲了发布前的审核窗口，是流程上的取舍而非纯便利。
能链接到：与「必须自己审一遍」的结论结合；封面必须预先准备好，与封面生图工作流联动。

## 行业洞察 / 求职

🧷 **[敏锐关键词] 医疗行业 head count 少，推荐人才会「挤爆」**
是什么：医疗行业前景不错，但招人名额（head count）很少、岗位不多，一旦被推荐，求职者会迅速挤满仅有的坑位。
为什么值得注意：打破「行业好 = 值得推荐」的简单判断——行业前景与岗位供给是两回事，稀缺供给下推荐会制造内卷、拉低个体成功率。
能链接到：求职辅导内容选品要把岗位供给稀缺性纳入；评论区用户反馈是真实的一手数据源。

## AI / 封面工作流

🧷 **[敏锐关键词] 生图封面定向编辑的两种 prompt 口径**
是什么：两个可复用的封面处理技巧——①给 AI「维持现有的风格，我给你重新定义一版内容，你帮我生成」；②「把现在这张图的文字全部去除掉，保留底色，其他地方你自己手敲」。
为什么值得注意：打破「生图 = 每次从零重新生成」的认知——基于已有图做定向编辑（去文字保底色 / 保风格重生成）能同时拿住风格一致性和文字精确性。
能链接到：直接支撑「封面生图工作流化」这个洞察；是封面黑屏问题复盘产出的实操解法。

🧷 **[敏锐关键词] 带教实习 + 模拟面试 = 现成的内容素材矿**
是什么：带教实习过程中跟别人讲的话题、以及模拟面试的场景，都可以每天发到小号上当案例。
为什么值得注意：打破「内容要专门想选题、专门录」的认知——日常带教、面试陪练本身就是高频发生的真实内容，采集成本近零。
能链接到：与小号案例日更策略绑定；是主号引流、小号承接闭环的素材来源。

## 账号定位 / 体系

🧷 **[敏锐关键词] 账号内容线要从光学扩展到智能硬件/智能生态**
是什么：近期要准备「整个链路怎么去构建」——账号不止做光学，还要覆盖整个智能硬件、硬件系统、智能生态，且目前还没想清楚这个系统该怎么弄。
为什么值得注意：打破「垂直账号 = 只做单一细分领域」的认知——个人账号可以按知识体系横向扩展，但系统化内容线要先设计链路，而非零散加内容。
能链接到：与用户「光学转智能硬件/影像 PM」的定位联动；内容体系规划要先于内容生产。

🧷 **[敏锐关键词] 主号输出 + 小号承接的账号矩阵闭环**
是什么：主号做内容输出和流量，小号做带教案例的总结归纳沉淀，并把主号流量引流到小号，两个账号平行坚持发。
为什么值得注意：打破「一个账号打天下」的认知——账号矩阵分工（主号引流 / 小号承接转化）比单账号堆内容更能沉淀私域。
能链接到：与「小号案例日更」洞察绑定；是求职陪跑服务的私域转化入口。
