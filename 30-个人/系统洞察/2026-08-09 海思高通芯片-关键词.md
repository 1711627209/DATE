## 技术 / 芯片选型

🧷 **[敏锐关键词] HI3516 CB610 入门开发板**
**是什么：** 海思最入门级芯片开发板，约 100 元，自带摄像头，淘宝/闲鱼购买即送全套 SDK 和技术文档。
**为什么值得注意：** 是海思 ISP 调试的最低成本入口，适合自学和原型验证；4K60fps 规格超出预期（Speaker 1 最初误以为是 720P30）。
**能链接到：** [[归类/技术知识]], 海思芯片选型, 自研工作台搭建

🧷 **[敏锐关键词] 高通 8550 开发板（万元级）**
**是什么：** 高通高端旗舰 ISP 平台开发板，单块售价超万元，算力达百 TOPS，用于大疆 Action、GoPro、影石等运动相机。
**为什么值得注意：** 代表消费级相机 ISP 调试的顶配平台；具备此平台经验是市场稀缺技能，溢价明显。
**能链接到：** [[归类/技术知识]], 高通平台调试, 职业溢价

🧷 **[敏锐关键词] 海思芯片型号命名规则（HI 后缀）**
**是什么：** 海思芯片型号以 HI 开头后接一串数字（如 3516、3559、928），不同型号对应不同应用场景（监控/直播/运动相机），支持的视频格式（1080P/4K/60Hz）各不相同。
**为什么值得注意：** 选型时必须对照规格表，不能只看型号数字大小；海思官网「专业影像/SOC」栏目是查询入口。
**能链接到：** [[归类/技术知识]], 芯片规格对照表, 海思官网导航

## 技术 / ISP 调试架构

🧷 **[敏锐关键词] AWB/AF 截流架构**
**是什么：** 在 raw 图像流进入海思原生 AWB（自动白平衡）和 AF（自动对焦）模块之前，将数据流抽出至自研平台处理，完成后再回传海思链路。
**为什么值得注意：** 这是绕过海思「可调参数少、自由度低、核心算法不公开」限制的工程解法；需要对 ISP pipeline 有深入理解才知道在哪里截流。
**能链接到：** [[归类/技术知识]], 自研 ISP 平台, 海思 API 替代

🧷 **[敏锐关键词] 海思调试工具链全览**
**是什么：** CRT（设备通讯）+ NFS Server（参数推送）+ Fast Stone Image View（图片查看）+ OBS（视频流拉取）+ Zoom Capture（抓图）+ CIMA Star（海思调试）+ Image G（MTF 客观分析）。
**为什么值得注意：** 这是一套完整的 ISP 调试工具生态，每个工具解决特定环节；自建工作台需整合这些工具。
**能链接到：** [[归类/技术知识]], 调试平台搭建, 工具链集成
