🧷 **[敏锐关键词] 简历拆解成精确任务再交给 AI**
是什么：改简历前先把简历拆解成"三大板块→每个项目→原文是什么/要不要改/怎么改"的明确任务，并给 AI 规定对话框架；否则"没有标准，你也不知道怎么改，全看模型强不强"，结果"还不如手敲"。
为什么值得注意：打破"把简历整份甩给 AI 一键改写"的流行用法——AI 失效的根因通常是任务没拆到可执行粒度，而非模型不够强。
能链接到：洞察块「AI 改简历先拆精确任务」；Claude Code 工作流、提示词框架。

🧷 **[敏锐关键词] 面试全程录音 → 知识库复盘闭环**
是什么：HR 面试和技术面试全部录音，复盘进知识库，提取不懂的点复制成框架去学习，再把痛点（人家问的就是人家在意的）加进简历；"只要一次面试出现的漏洞，就再也不会出现第二次，面个三五次基本上不可能不会了"。
为什么值得注意：打破"面完就翻篇"——面试问答是最新的考点集，面试本身是最高效的信息采集渠道，闭环后每面一次就补一次盲区。
能链接到：洞察块「面试录音复盘闭环」；面试复盘、知识卡提取。

🧷 **[敏锐关键词] 面试时放豆包/AI 基于知识库实时辅助答题**
是什么："面试完之后你可能不会，但你可以放旁边放个豆包最好，它根据你知识库帮你去回答，只要停顿个 3 秒钟，你的答案就出来了"。
为什么值得注意：打破"面试全靠临场发挥"的预设——个人知识库+AI 实时辅助把积累变成临场能力，是一套可复制的实操打法（注意需在合规边界内使用）。
能链接到：洞察块「面试录音复盘闭环」；面试准备、知识库即席检索。

🧷 **[敏锐关键词] 招聘平台简历隐私：假名+假年龄+隐藏当前公司**
是什么：上招聘平台前把名字改成"豪先生"、年龄改成 32 岁、隐藏相关公司，因为"我都能看到你简历啊"——现公司和 HR 都能看到在线简历；核心原则是"你只要简历是真的就行了，你简历不往外发就行了，其他东西都可以假的"。
为什么值得注意：打破"在线简历=实名档案"——招聘平台简历是半公开资产，身份信息（名字/年龄/现司）可脱敏，只有简历内容必须是真实的。
能链接到：boss 直聘设置、求职隐私保护、在职跳槽风险。

🧷 **[敏锐关键词] 简历技能排序：Python 在前，MATLAB 在后**
是什么："你放 MATLAB，人家不一定认，先写 Python 吧，然后再想 matlab"；技能列表顺序按目标岗位招聘认可度排，而非按自己熟练度/项目用量排。
为什么值得注意：打破"按熟悉程度排技能"的直觉——技能顺序是给 HR 的第一层信号，要先放对方认的名字。
能链接到：洞察块「简历写平台词」；简历关键词优化、ATS 解析。

🧷 **[敏锐关键词] 简历措辞用"擅长"，不用"使用/精通"**
是什么："使用海思，这些措辞有问题"——应写"擅长海思等平台的调试"；"擅长。擅长。擅长就行了"，刻意避开"精通"。
为什么值得注意：打破"越强越要写精通"——"擅长"是安全值，避免措辞夸大被面试当场拆穿，同时覆盖面更宽。
能链接到：洞察块「简历写平台词」；简历真实性、面试追问防线。

🧷 **[敏锐关键词] 简历写平台词而非 ISP 内部细节**
是什么："我为什么让你写这些平台？就是他们只认这些平台……他不会懂 ISP 里面具体所有东西，他可能会懂：你会这些平台，你会这些平台，挺好的"。
为什么值得注意：打破"简历要写满技术深度"——筛选层（HR/转岗工程师）不读细节，平台关键字才是第一层匹配信号，ISP 内部细节是面谈才谈的内容。
能链接到：洞察块「简历写平台词」；海思等 ISP 平台、关键词匹配。

🧷 **[敏锐关键词] 量产问题清单化（量产工艺知识库图谱）**
是什么：把过去所有量产问题整理成一个 list 表格，设计新品时过一遍提前规避；"以前你必须要记在脑子里面随时反应，现在你不需要，现在它变成一个知识库图谱"；工厂进度表、良率处理/筛选逻辑资料都值得 copy 进库。
为什么值得注意：打破"量产经验只能靠记在脑子里的老师傅"——经验可外化为随时调用的清单，避免重复踩坑，每省一次试产时间就是价值。
能链接到：洞察块「量产问题清单化」；量产工艺、良率管理、SOP 外化。

🧷 **[敏锐关键词] 保密文件脱敏复用：脱敏文件+对照文件双份**
是什么：公司保密文件不能直接发→让 AI 加噪声/扩写/改措辞/改文章结构顺序但保留核心信息，图片用 GitHub 开源工具做分割化处理→输出"一份脱敏文件加一个对应对照文件"，脱敏版发网上无人能认出是哪个公司，对照版自留。
为什么值得注意：打破"公司资料离职就没了/不能碰"——合法脱敏后能把工作资料沉淀成个人知识库资产，也能安全分享给朋友互惠。
能链接到：洞察块「保密文件脱敏复用」；知识库建设、内容资产沉淀。

🧷 **[敏锐关键词] 寻影 T2 相机规格：0.98" 大底 + 200mm 级长焦，已上市公开**
是什么："0.98 分之一，约等于 1"，T2 是接近 1 英寸的大底，"它长焦是多少焦段？有 200 吗"，"已经上市了"，参数公开；寻影锐魔产品线里还有"太阳号"（孙超他们要打的机器不是太阳号）和 S1。
为什么值得注意：打破"AI 相机=小底网络摄像头"——寻影这类 AI 相机已上近 1 英寸大底走高画质路线，且有可查的公开规格，是竞品调研的一手样本。
能链接到：竞品调研、AI 相机、传感器选型（个人-23 洞察的传感器格局）。

🧷 **[敏锐关键词] 核心变焦镜头参数连自家工程师都保密**
是什么：朋友公司"最的一颗镜头是可以变焦的，但是那一颗镜头的具体参数我们现在还不知道，我领导肯定知道，捂得贼严实"。
为什么值得注意：打破"项目成员都知道自己产品参数"——核心光学方案保密级别高到只给领导层，做竞品调研时别指望从一线工程师拿到，反推竞品参数要走公开资料/拆机。
能链接到：竞品调研方法论、光学保密、产品参数获取。

🧷 **[敏锐关键词] 网球赛事低成本多机位转播方案：两台 iPad + 两台巡影相机**
是什么：一台相机放观众席，"两个 iPad、两台巡影"做网球多机位转播；寻影生态 APP 可在手机上控制变焦、滤镜，支持无线热点、RTMP/RTSP 推流。
为什么值得注意：打破"专业转播=昂贵的广电系统"——AI 相机+平板+无线推流就能组低成本多机位转播，这是此类相机产品切入的实际细分场景，也是产品方案做竞品对标时的参考案例。
能链接到：竞品产品方案、AI 相机场景、体育转播方案。

🧷 **[敏锐关键词] Obsidian 插件生态 6000+，可让 AI 一键推荐/安装/配置**
是什么："它插件库老多了，6000、6625 个插件，但你不知道怎么样"——可以让 AI 根据知识库推荐 20 个插件并给出理由、再"一键装上去、一键使用"；MCP 让 Claude Code 能直接操作（如"把我这里面的简历同步到其他平台"招聘网站）。
为什么值得注意：打破"插件靠人肉翻+手装"——庞大生态需要 AI 做代理来选择/安装/配置，人只做审核，Obsidian+AI+MCP 已经能驱动招聘平台这类外部动作。
能链接到：洞察块「AI 改简历先拆任务」；Obsidian 插件、MCP、自动化工作流。

🧷 **[敏锐关键词] AI 重度使用真实成本：200 元/天、生图 14 元/天、积分不够用**
是什么：孙超火山引擎"充 200 块钱"，"今天用了挺多钱的，用了十几几十块钱，我的图片都生成 14 块钱了"；朋友 Claude 花"20 块钱，快用完了"；Workbar"每天才 100 积分，不够用"。
为什么值得注意：打破"AI 免费/几乎不要钱"——多模型重度使用（对话+生图）真实成本是每天几十元级，做副业/知识库要提前把 API 预算算进成本结构。
能链接到：洞察块；火山方舟 API、技术成本、副业成本核算。

🧷 **[敏锐关键词] 外包岗是无效流量：软通动力"当它没有"，但光学/传感器岗可聊**
是什么：boss 直聘上找上门的软通动力等外包公司，"这种你就当它没有就行了"；但"他是做光学工程师、传感器啊，这个倒可以聊一聊"。
为什么值得注意：打破"有 HR 找就是机会"——外包岗要用过滤心态处理，但要按岗位方向（光学/传感器/ISP）筛出真正值得聊的机会，而不是一刀切忽略。
能链接到：求职筛选、外包识别、光学岗位机会。
