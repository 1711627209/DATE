## 创业认知

### 🔖 [创业认知] 艾灸机器人降本路线：3D打印把机械臂压到1000多 + "养生器械"擦边认证 + B2B2C渠道

完整方案推演。起点是消费类 vs toB 的"性感"判断：toB 需要 background 和具体方向的内容，而做消费类你必须懂客户、懂市场、懂为什么你的客户愿意买单，所以消费类更性感。对标市面：普通艾灸机器人价格普遍上万，一个很大的仪器加一个机械臂，都是认证过的医疗器械，只能卖到医院、养生馆，或者因为太贵用月租形式销售——做不成消费级。降本路径：市面大量六轴机械臂价格不低于 5000 块，整个金属支架如果用 3D 打印，一下降到 1000 多块钱；再加一个特殊艾灸头，烧完的烟雾被吸走，家庭环境不会烟雾缭绕（否则自己在家灸，第一找不到方位，第二烟雾吸进肺伤身体）。合规路线：查过可以不做医疗器械、先做"养生器械"擦边，先做消费类，验证阶段（MVP）再反过来，用理疗师的经验来确认穴位可靠性。渠道模型 B to B to C：通过艾灸馆、小理疗馆（只有一两个理疗师、人多时需要人机协作）卖给已体验过艾灸还想继续的客户，先不做医院；同时可做出海，海外对中华传统背景有天然的"玄学"接受度。用户画像：医生建议做艾灸的疼痛患者（刚性）+ 儿童患者（更需细节）。因果链：市面产品贵且是认证器械 → 3D打印降本到消费级 → 擦边养生器械绕开认证 → B2B2C 借理疗馆验证与出货 → 出海放大。

### 🔖 [创业认知] 盲人眼镜的"共识陷阱"：强大共识背后没人做出来的产品，问题往往在商业化而非有效性

导师对每年都出现的盲人眼镜项目的判断。每年都有盲人眼镜的项目，但好像没有人做出来；"一个强大的共识背后，没人做出来的产品，它一定是有问题的"。它也许是有效的，但问题可能不出在产品有效性上，而是出在商业化：1731 万视障者里有多少是 60 岁以上的老人（学员答 60% 以上）？你都 60 岁又盲了，这个东西怎么卖给他？他大部分时间可能就是物质上养成了习惯、用不上；而且你得研究盲人用户买盲人产品的渠道——一个盲人不可能去电商，也不可能用别的渠道，你甚至不知道他究竟是怎么买东西的，这又是一个要研究的点。因果链：强共识 + 多年无人做出来 → 一定有隐藏问题 → 排除有效性后锁定在"又老又盲的用户 + 不可达的购买渠道" → 商业化的死结才是真问题。

### 🔖 [创业认知] 乡村医疗挂号：真需求，但方案推演到最后是"政府行为"，创业判死

一段完整的需求验证与判死过程。提出者（非医疗背景，来自偏远乡村）给出数据：四五线城市、乡镇能用手机挂号的比例只有 16.8%，而这部分人群占中国人口至少 1/3；他们找医生的方式是熟人——读过费孝通《乡土中国》就知道，熟人社会是底层资源获取方式。方案：在社区医院/乡村卫生所做极低门槛的"刷身份证"终端（老人字体开到最大那种水平），刷一下，历史病历全在系统里，告诉他县城/市区医院明天后天哪个专家有号、怎么去。但导师连环拆解：其一，这本质是医疗资源缺乏的问题——你建一个中枢也解决不了资源缺，只能做调配（有些医院确实有资源但是空缺了）；其二，手机覆盖率已经很高，除了手机还有没有更靠谱的触达每个老人的设备？要干掉 16.8% 到 60% 这一步很难发散，也许比"手机+卫生所"更靠谱的方案很难找到（陪诊服务是真人的部分解法，但那是真人）；其三，最终推导出来它是一个政府行为——还需要当地附近几个医院信息互通，而信息互通本身就是极难打通的。结论："当我们觉得它是个政府行为的时候，这个就很难创业。" 因果链：真实痛点 + 数据支撑 → 解法依赖"资源缺乏而非缺调度" → 触达渠道与信息互通都卡在体制 → 推演为政府行为 → 创业难。

## 行业洞察

### 🔖 [行业洞察] 穿戴设备从"采集"到"预警"的价值跃迁：慢病急性发作监测是空白

对慢病监测赛道的系统判断。现状：穿戴式监测设备（指环、手表、各种佩戴式）最主要的功能是采集数据；但"预警"板块才是非常有价值、患者非常需要的东西——疾病在危急情况下如果做到及时预警，能有效挽救患者生命。癫痫监测预警装置是样板：采集生物电信号 + 运动模型，综合病情做评估，已有公司在一个月前把产品做出来了（方向被市场验证）。拓展逻辑：佩戴这类设备的患者大多有慢性病 + 有监测需求 + 该病有急性发作且急性发作有危险，这类疾病才具有监测预警价值——癫痫（倒地摔伤）和 COPD 慢阻肺急性发作（呼吸困难、缺氧、大脑受损）就是典型。现有方案的缺口：COPD 监测主要靠 Apple Watch 这类平台测血氧和外围指标，但它不是专门为 COPD 做的，模型拟合度较低、应用价值有限，而且没有疾病发生时的预警功能。方案：综合数据评估病情 + 个性化（导师提到的"虚拟人"构建）+ 在疾病发生前提前预警。衍生方向：湖南省级医院发现大量 COPD 病人用药是错的、用药量不对导致病情维持不佳——慢性病监测设备通常该搭载用药建议、联系主治医生、生活建议，并构建患者-设备-医院的数据链。因果链：已有设备只采集不预警 → 预警是患者刚需且被癫痫案例验证 → 慢病急性发作（COPD）是天然空白 → 综合多模态+个性化虚拟人+前置预警填补 → 用药管理是配套变现点。

### 🔖 [行业洞察] 司美格鲁肽减重反弹的机制盲区：同遗传背景的表型差异是预测模型的机会

从实验室现象推到产品机会的完整链。做肥胖小鼠实验时发现：相同遗传背景的双胞胎小鼠、相同设置条件、相同运动量、严格管控之下，肥胖表型仍然有显著差距；查阅资料发现美国彭宁顿研究中心用人做了对应的人体实验。这个发现直接关联当下大火的减肥药：司美格鲁肽（李来等做的肥胖药物）用药后减重、停药后仍然肥胖——这个反弹的原因机制可能就在"同遗传背景仍表型差异"这一点上，即环境与努力之外还有未被量化的个体差异。产品落点：基于实验室数据做智能体重秤（Metable Care），专门对接已经接受过用药的人群——这类人依从性更高、已经花费了价值、更希望自己的美观和健康得到保证。核心监测指标：FM（fat mass 脂肪量）、fat free mass（去脂体重）+ 一套预测算法模型；产品形态 = 体重秤 + APP + 检测仪，对接临床医生和患者。市场判断：打"视频流量"（司美格鲁肽相关）越来越多了，市场很大。因果链：双胞胎同条件下表型仍显著不同 → 彭宁顿人体实验佐证个体差异机制 → 解释减肥药停药反弹 → 用预测模型监控反弹 → 锁定已用药高依从人群做落地。

### 🔖 [行业洞察] 中医消费级的"个性化"死结：太个性化就没法做成标品

对中医作为消费级产品的否定性判断。中医作为一个消费级产品，最大的问题是太个性化——每个人对中医的想法不同，就很难用一款产品覆盖每个人；没法做成标品，就没法做大。因果链：个体认知与体质差异大 → 无法用单一产品覆盖 → 做不成标品 → 消费级商业模式立不住。

## 技术知识

### 🔖 [技术知识] 失眠的医学有效性论证：腺苷机制是产品能否成立的第一关

对"睡前记录/失眠产品"的评审标准。按医学原理，一个失眠的人应该是腺苷分泌不足，那么"做这件事腺苷分泌就能出来的原因又是什么？"——如果说不清楚，产品叙事再动人也是空中楼阁。提出者（Ende 失眠硬币）的反驳也成立：失眠影响因素很多，哪怕吃褪黑素，脑子里面还是在想东西，它只是制造了困意、说"我不行我要睡"，并没有消除思维。导师收敛的结论：有效性是核心，医学上的有效性；这个只要过了，有效性就很明显。因果链：失眠的医学机制是腺苷不足 → 产品的疗效必须有机制可循 → 褪黑素只造困意不除思维 → 有效性（而非体验/叙事）是第一道也是唯一硬门槛。
