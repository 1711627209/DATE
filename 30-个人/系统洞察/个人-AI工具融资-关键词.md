## 融资认知

🧷 **[敏锐关键词] 投资人投人不投点子（普通人 vs 名人的入场券差异）**
是什么：投资人给钱主要看创始人和团队，不是看点子——没产品没用户也能拿投资，只是没用户时估值低；除非创始人已有成功履历（此时投的几乎都是合作过或非常知名的创始人）
为什么值得注意：打破「没有产品/用户就没有融资资格」的普遍认知，也解释了为什么同一条赛道普通人拿不到钱、名人轻松拿到——关键变量是「人」的履历
能链接到：[[2026-08-19 AI工具创业规划-洞察]]（产品能卖钱 vs 项目能融钱、融资归责）、求职定位、创业认知

🧷 **[敏锐关键词] 投资人只做锦上添花，不做雪中送炭（99%）**
是什么：至少 99% 的投资行为是锦上添花而非雪中送炭；投资人真正怕的是「错过好团队好机会」
为什么值得注意：创业者常把融资当「救命」，实际投资逻辑是「你快要成了才进场」——所以普通人的正确策略是先把事情做出闭环，而不是到处找钱
能链接到：融资方法论、创业认知、闭环原则

🧷 **[敏锐关键词] 每件事都要闭环（不闭环 = 白干）**
是什么：一件事要么不做，要做就闭环到底（有结果交付、能展示），不能悬在半空
为什么值得注意：从融资到日常工作的通用原则——不闭环就产出不了可展示的成果，等于浪费投入
能链接到：求职 STAR、副业推进、行动项

## AI / 工具

🧷 **[敏锐关键词] Codex 不让中国 IP 注册（地区封锁）**
是什么：OpenAI 的 Codex（编程 agent）拒绝中国 IP 注册，中国大陆用户直接买会员也不行，等于被封杀
为什么值得注意：打破「有海外账号/付费会员就能用」的认知——这类工具的真实可及性门槛比表面高，国内用户需要额外方案
能链接到：AI 工具选型、技术成本、出海/镜像方案

🧷 **[敏锐关键词] 中转站 API = 绕过地区封锁的通行做法**
是什么：被地区封锁的工具（如 Codex）可通过购买第三方「中转站」的 API 来调用，不用自己搞定注册和 IP
为什么值得注意：给出「被封锁工具怎么用」的实操路径；代价是要评估账号与数据风险
能链接到：AI 工具可用性、技术成本、API 经济

🧷 **[敏锐关键词] Claude Code 接 DeepSeek = 被封锁工具的替代组合**
是什么：用 Claude Code（编程 agent 工具）接 DeepSeek 模型，组成替代被封工具的组合，用户实测可用
为什么值得注意：主流 Agent 工具 + 国产模型的混搭是当前普通用户的高性价比方案，不绑定单一厂商
能链接到：AI 工具选型、技术成本、已有「超弟 = Claude Code 智能体」

🧷 **[敏锐关键词] Workbody 干不了复杂任务**
是什么：Workbody（AI 工具）处理简单任务可以，但复杂任务干不了，需要换能力更强的 Agent
为什么值得注意：通用工具与专用 Agent 的能力边界——复杂任务需要能编排多步的 Agent，选型要按任务复杂度
能链接到：Agent 能力分层、复杂任务编排、大模型分层选型

🧷 **[敏锐关键词] 天工 AI 充值 300+ 做 PPT，做了好几版仍不好**
是什么：用天工 AI 做 PPT 充了 300 多，且不是一次性生成，做了好几版效果都不理想
为什么值得注意：付费 ≠ 好结果；同样的事用方法得当的免费工具（豆包）也能做，工具能力与「会不会用方法」强相关
能链接到：技术成本、AI 原生 PPT 方法、AI 效率

## 自媒体 / 自动化

🧷 **[敏锐关键词] 微信 = 最方便的 AI 接入接口**
是什么：把 AI 机器人接进微信，往群里/对话里发链接（视频、博主、IP），它就自动按预设工作流解析、做竞品分析、搜集全网资料
为什么值得注意：个人 AI 工作流的入口之争——微信群聊是最高频触点，比打开网页/App 省时间，天然适合被动式采集
能链接到：AI 工具、内容采集、自媒体自动化

🧷 **[敏锐关键词] 16 小时视频反解 = 试 AI 能力底线**
是什么：让机器人去反解一个 16 小时的视频，目的是「尝试它的底线」——验证它能处理多重的输入
为什么值得注意：普通人把 AI 当黑盒用，这是用极端输入主动探测 AI 真实能力边界的方法，测完才知道工作流的上限在哪
能链接到：AI 能力评估、长视频处理、内容转写

🧷 **[敏锐关键词] 批量链接定时整理 + 产品耦合建议**
是什么：把群里所有人发的链接统一定时整理 → 分布下发 → 对每个链接单独调研 → 生成文档 → 再结合「自己公司的产品」做耦合建议
为什么值得注意：把信息采集变成可复用的被动流水线，还能和自身业务（产品/内容）做耦合——竞品情报的低成本玩法，不用每天手动点开
能链接到：竞品分析、内容选题、自媒体战略

🧷 **[敏锐关键词] 技能比结果更值钱（教方法 vs 代做）**
是什么：「先把你教会，你得掌握这个技能，技能比会更值钱」——比起帮对方做出一版 PPT，教会方法/技能的价值更高
为什么值得注意：服务设计、求职加分、知识服务的核心都在于「给方法」而非「给结果」；也是内容/咨询变现的底层逻辑
能链接到：求职方法论、知识服务、内容卖点
