# 个人-65 马术运动影像数据采集-西电广研院交流-关键词

> 敏锐关键词：零散但打破信息差的关键信息点

---

🧷 [敏锐关键词] 武当功 = 海思 8核A73（华为芯片营销名）
是什么：华为海思一款芯片的市场营销名称，是当前中国能拿到的最高算力级别之一——8核A73，支持8K、多路ISP，但GPU能力弱。
为什么值得注意：打破"国产芯片性能逼近旗舰"的模糊认知——具体到能拿到手的水平，就是8核A73这个档位，再往上就没有了。
能链接到：国产芯片选型、供应链、高帧率相机硬件

🧷 [敏锐关键词] 海思 + RK3588 双芯片组合方案
是什么：影像主控用海思芯片（负责成像、画质、多媒体），算力任务用瑞芯微3588（两个摄像头跑YOLO基本没问题）——画质与AI算力分离。
为什么值得注意：打破"一块主控芯片打天下"的认知——专业影像产品常采用双芯片分工，各自干擅长的事。
能链接到：硬件架构、影像主控选型、摄像头模组

🧷 [敏锐关键词] ARM V9 授权限制（V11拿不到）
是什么：ARM是英国公司、软银控股、中国参股约5%，但仍对中国区别对待——授权最高到V9，V11以上板上钉钉不给，属政治问题。
为什么值得注意：打破"ARM是开放架构谁都能用最新版"的认知——最高版本授权中国拿不到，直接决定国产芯片上限。
能链接到：芯片供应链、全球化产品、美国市场选型

🧷 [敏锐关键词] 影石 / 大疆 48T-60T 稠密算力
是什么：影像厂商已经在相机/运动相机里堆到48T-60T稠密算力，摄影积累很深。
为什么值得注意：打破"消费相机算力需求低"的认知——摄影公司的算力投入远超想象，这是被忽视的军备竞赛。
能链接到：竞品对标、硬件成本、算力选型

🧷 [敏锐关键词] 大疆只招应届生 + 西电硕士51万 / 通信70万
是什么：大疆只做校招自己培养、几乎不招社招（社招思维固化难扭转）；西电硕士进大疆嵌入式51万（约等于211博士价），通信方向今年最高70万。
为什么值得注意：打破"大厂偏爱有经验的人"和"硕士50万是神话"的双重认知——应届身份是进自培养型大厂的最佳窗口。
能链接到：求职方法论、薪酬对标、影像赛道行情

🧷 [敏锐关键词] 英伟达盒子 6000→13000 卡脖子
是什么：码头项目用英伟达Jetson系列盒子做端侧推理，项目期单价从6000元涨到13000元，成本翻倍直接导致项目无法推广。
为什么值得注意：打破"芯片涨价只影响大厂"的认知——中小企业端侧AI的成本对芯片价格极其敏感，一个涨价就毁掉整个项目。
能链接到：技术成本、供应链风险、端侧计算

🧷 [敏锐关键词] 事件型相机（只回传事件，不传视频）
是什么：平时不传视频，只回传有信息的事件；码头24小时只有不到1小时有人，无人时算法不启动。
为什么值得注意：打破"视频监控必须全量回传"的认知——按事件过滤极大降低带宽和存储成本，是端侧AI的关键商业模式。
能链接到：数据带宽、端侧计算、马术影像传输

🧷 [敏锐关键词] DVS 事件相机（仿苍蝇眼睛/鹰眼）
是什么：动态视觉传感器——静止的目标看不到，一动就响应；拍网球、羽毛球、乒乓球等高速小目标时球划过一条线非常清楚。
为什么值得注意：打破"高速拍摄只能靠高帧率"的认知——高帧率/插帧之外还有事件相机这条技术路线，专门解决光学摄像机会丢的高速目标。
能链接到：高速运动影像、马术/网球拍摄、传感器选型

🧷 [敏锐关键词] UWB TAG 超宽带射频定位（不是视觉）
是什么：每个目标身上挂一个很轻的射频芯片标签（UWB超宽带，斯德哥尔摩大学2004年论文起源，现已商业化20年），靠射频定位，不受视觉干扰。监狱犯人出外勤、运动员多人定位都可用。
为什么值得注意：打破"多目标识别必须靠视觉"的认知——射频标签方案在遮挡/干扰场景下远比视觉可靠。
能链接到：多目标跟踪、体育拍摄选型、监狱安防

🧷 [敏锐关键词] Skeleton 骨架识别 75维特征打分
是什么：行为识别不用RGB像素，只提取人体骨骼姿态（75个维度特征）做分析，可自由组合打分——谁动作没做到位不计数、专业运动员曲线对比。
为什么值得注意：打破"行为识别必须用像素"的认知——降维后暗光可用、实时性好，还能把马术裁判的主观打分量化成数据。
能链接到：马术裁判打分、病理步态分析、运动训练

🧷 [敏锐关键词] 自建数据集：学生跳楼 + 假人每20米枚举
是什么：做坠落检测，让学生在2米高台半夜往下跳拍摄（等园区停电抓黑光机会）；现场验证用假人穿工作服从0到170米每20米扔一次枚举所有距离。
为什么值得注意：打破"数据集靠买靠开源"的认知——特定垂直场景的数据要自己用物理世界搭建，工程量大到离谱但别无他法。
能链接到：数据构建方法论、生成式AI替代、实测验证

🧷 [敏锐关键词] 虚拟围栏 / 事件触发区域（用逻辑代替预测）
是什么：固定场地（码头、马术场、网球场）画若干个虚拟围栏，不同区域用不同算法和触发逻辑，用逻辑判断代替预测模型，算法极其简单。
为什么值得注意：打破"智能拍摄必须上预测模型"的认知——固定场景可以先逻辑化简化，预测是更高阶但非必需的方案。
能链接到：马术/网球拍摄架构、场景定标、事件触发

🧷 [敏锐关键词] 超聚合数据平台 vs 华为5亿南网巨系统
是什么：华为给南方电网做了5亿项目（催生南网数科），每年光养平台花几千万；他们做"超聚合"轻平台——通信/数据/逻辑/运维全聚合。
为什么值得注意：打破"平台越大越好"的认知——大平台运维成本是隐性杀手，中小企业用聚合式轻平台定位打差异化。
能链接到：工业软件商业模式、创业定位、OT/IT

🧷 [敏锐关键词] 运维聚合才是命门（Windows回迁）
是什么：系统迭代8年从Windows迁到Linux又被迫回迁Windows——客户搞不定Linux，普通网工只会Windows，当年ETC全用Linux推不动。
为什么值得注意：打破"技术先进就能落地"的认知——对客户系统可维护性的考量往往比技术先进性更重要，这也是B端项目的隐性成本。
能链接到：工业软件落地、产品化、客户成功

🧷 [敏锐关键词] 实测数据 = 自己搭建的环境也算
是什么：算法有两个评价体系：数据集（实验室跑准确率）和实测数据——现场/自己搭建的环境都算实测，不必与真实场地一模一样，关键是有真实目标做真实动作+多角度机位采集。
为什么值得注意：打破"必须去真实现场验证"的认知——搭建还原环境是可接受的验证路径，比纯数字孪生更接近真实。
能链接到：数据构建、数字孪生、验证闭环

🧷 [敏锐关键词] 生成式AI替代真实数据采集（李飞飞世界模型）
是什么：生成式AI可以生成训练数据（不用真人真跳），但李飞飞的世界模型投了几十亿美金还没搞出来——物理世界建模极难，生成精度和运动规律是否符合真实存疑。
为什么值得注意：打破"生成数据马上能替代真实采集"的认知——物理规律这块目前还是硬骨头，实地拍摄仍更准。
能链接到：AI数据未来、自建数据集、数据成本

🧷 [敏锐关键词] 西电广研院异地研究院模式
是什么：西电2020年与广州市政府共建异地研究院（中新知识城），教职工500+、在校硕博200+、有工程博士点，核心任务是承接企业横向技术攻关。
为什么值得注意：打破"高校老师不能接活"的认知——从国家到学校政策都鼓励老师走出学校做产学研转化，企业可以带需求/带资进组对接。
能链接到：创业认知、高校合作、技术转化

🧷 [敏锐关键词] 三级安全分级（码头落水）
是什么：一级无人时段闯入电子围栏（声光电警告）→二级不穿救生衣进区域（抓拍罚款）→最高级坠落动作（电话直达一把手+现场+各级）。
为什么值得注意：打破"AI监控只是报警"的认知——按风险分级联动声光电+自动拨号，安全事件的触发链路能直达最高决策层。
能链接到：安全生产、ToB需求、事件联动

🧷 [敏锐关键词] 智能艾灸机器人（CV+穴位识别+热力图）
是什么：机械臂+CV识别人体穴位做艾灸，配热敏传感器输出灸前灸后热力图对比，自动识别躺姿、自动吸烟——市面上还没见到做到这个程度的。
为什么值得注意：打破"医疗机器人门槛很高"的认知——高校横向项目就能把CV+传感+机械臂做成有差异化的产品。
能链接到：CV落地、医疗器械、横向项目机会

🧷 [敏锐关键词] 高通偏计算摄影那套（高帧率+高画质）
是什么：高通平台能玩高帧率加高画质，偏计算摄影那套，8K也支持；高帧率主要靠主摄像机和量产选型解决，不能用插帧差值（差值质量差）。
为什么值得注意：打破"帧率上不去只能靠插帧"的认知——镜头原生高帧率+大算力才是正路，差值只是妥协。
能链接到：影像主控选型、运动相机、高帧率控制
