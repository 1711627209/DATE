> 说明：许凯「光学唠嗑」直播，主线是 AI 工具与个人成长，附光芯片科研方向提问。零散但打破信息差的关键信息点如下。

---

🧷 [敏锐关键词] DeepSeek V4 API + Claude Code：约 300 元/月的个人全栈 AI 自动化方案
是什么：许凯给出的个人级 AI 配置——DeepSeek V4 模型 API 对接 Claude Code，一次充值约 300 元，只要不是天天重度跑，够用一两个月；可承担定时查岗位、抓开源代码、部署本地定时任务等全局自动化。
为什么值得注意：打破"要玩全局 AI 必须上贵模型/贵订阅"的认知——国产 API 的便宜组合已足够跑个人高频自动化，成本被压到每月百元级，个人求职与情报自动化由此成为可行项。
能链接到：技术成本、[[个人-16-电话沟通-洞察]]（猎头佣金高薪逻辑）中的求职自动化管道

🧷 [敏锐关键词] 腾讯 WorkBody 每日额度：一个复杂任务就耗尽
是什么：许凯实测腾讯的 WorkBody 全局 Agent，"每天额度有限，我处理一个复杂任务，它的额度就没有了"——示例是喂数据生成竞品报告，一次就耗光当日额度。
为什么值得注意：打破"大厂新出 Agent=免费好用"的直觉——这类云端全局 Agent 的额度约束远比本地 API 严格，重任务（如整份竞品报告）一次就打满配额，不适合高频/重负载场景。
能链接到：技术成本、[[个人-16-电话沟通-洞察]]（竞品/公司背景调研）

🧷 [敏锐关键词] GPT 5.6 命令行版：复杂任务效率高、生态友好
是什么：许凯提到最新 GPT 5.6，建议"用 Codex 去做复杂任务会非常好"，并实测命令行版 GPT"效率非常高，而且生态比较友好"。
为什么值得注意：打破"命令行/API 是开发者玩具"的认知——命令行入口把复杂任务拆解与执行变成可脚本化流程，配合 Codex 这类 agent 化工具，重任务可以交给命令行而非只能靠图形界面。
能链接到：技术知识、[[个人-26-讨论-洞察]]（若含 AI 工具选型）

🧷 [敏锐关键词] 全局 Agent 权限：给权限可读取整台电脑所有信息
是什么：许凯指出 Codex、Claude Code、WorkBody 这类全局工具"只要你给权限，它可以全局管理你的电脑上读取所有的信息"；他也给出工程上的一条铁律——信息喂多了 AI"上下文过长会饱和"，所以"就得不断不断去分"（手动拆对话/拆任务）。
为什么值得注意：一面是能力面——全局权限让 AI 能自主操作整台电脑（读文件、跑任务、定时循环）；另一面是风险与工程面——权限即泄露面，且上下文有硬上限，长任务必须主动切片，否则会饱和掉精度。
能链接到：技术知识、创业认知、[[个人-16-电话沟通-洞察]]（信息差资产的运维成本）

🧷 [敏锐关键词] AI 定时任务自动查 BOSS 岗位：求职盯梢无人值守化
是什么：许凯演示的用法——让 AI"定时去查岗位，搜各种 BOSS 上的岗位"，自己上网找开源代码、部署成定时任务，每天循环跑，把你在意的信息收集起来发到指定地方。
为什么值得注意：打破"找工作靠手动刷招聘软件"的常规——岗位发布即抓取、新机会即推送的无人值守盯梢，把求职从"人工低频刷"变成"AI 高频监控"，岗位信息差被自动抹平。
能链接到：求职方法论、job-targets-pipeline、[[个人-16-电话沟通-洞察]]（猎头岗位入口）

🧷 [敏锐关键词] 光芯片计算 / 光量子科研方向：大一新生想进组
是什么：直播中一位天大大一学生对"光芯片计算"感兴趣，想进组做科研，在官网看到意向导师"好像做光量子之类的"方向。
为什么值得注意：打破"光学就业只看镜头/激光雷达"的窄视野——光计算/光量子是光学硬件的前沿科研分支，存在真实的本科生科研入口；对关注光学赛道的 PM 而言，这是产业图谱里值得单列的一支（未来算力/光子计算）。
能链接到：行业洞察、[[个人-13-光电专业学生就业方向规划-洞察]]

🧷 [敏锐关键词] 赛博分身：AI 从"相反视角"帮你发现盲区，被动式成长
是什么：许凯的构想——把个人琐碎信息蒸馏成一个跟价值观对齐的赛博分身，"能从你相反的视角里面去帮助你发现你自己没有注意到的观点/道理"，人"只能关注到前方，没办法环视自己"，所以需要这样的外部反馈来被动补齐短板。
为什么值得注意：打破"成长靠自我复盘/主动求教"的单一路径——用 AI 画像对照"完人目标态"反推缺陷，把自我审视变成可量化的被动反馈机制；其前提（画像要清晰、诚实）本身就是对个人信息资产价值的重估。
能链接到：自媒体战略、[[个人-16-电话沟通-洞察]]（垂直私域=信息差资产）

🧷 [敏锐关键词] 深圳 AI 活动圈：线下入圈认识新奇技术
是什么：许凯自述常参加深圳的 AI 相关线下活动，感兴趣的朋友可以联系他一起去，"认识很多新奇的技术"。
为什么值得注意：打破"AI 技术只看线上文章/教程"的认知——深圳有活跃的 AI 线下活动圈层，是低成本接触前沿技术、攒人脉的入口；对想转智能硬件/AI 应用的人，线下圈子比线上信息源更快触达技术热点。
