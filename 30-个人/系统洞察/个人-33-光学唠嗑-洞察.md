### 🔖 [自媒体战略] 自我蒸馏与精准画像：把碎片信息蒸馏成 AI 赛博分身，靠"相反视角"被动补齐短板

一套完整的个人 AI 认知系统构想。第一步是"把所发的、个人零零碎碎的琐碎信息集合在一个地方"——这些信息不用担心有没有风险（那不是目的，只是后面要考虑的），集合的目的是"方便我们有自己的一个赛博分身，它可以帮我们处理很多判断的事情"。第二步是让这个分身"跟你的选择、价值观比较符合"，于是它可以帮你做很多决策，甚至"能从你相反的视角里面去帮助你发现你自己没有去注意到的一些观点、道理"，辅助快速在认知上成长——因为"我们人只能关注到前方，没办法去环视自己，不能观察到自身的短板，需要别人的反馈"。第三步是 AI 在蒸馏画像的过程中，"以一个相对完人的、你目标的这样的一个基础去看你现在这个状态，你缺什么，它给你提什么意见"，是"被动去发掘"而不是我们主动发掘。因果链：信息集中 → 价值观对齐的画像 → 赛博分身 → 相反视角反馈 → 被动补短板 → 认知快速成长。前提条件：把人物画像描述得足够清晰、足够诚实，否则分身失真。

### 🔖 [技术成本] 个人 AI 工具链选型：任务复杂度决定用哪个模型，重活贵活错开额度

一套基于"额度与成本约束"的工具选型逻辑。主力工具是 Codex 和 Claude Code；最新出的 GPT 5.6，"用 Codex 去做复杂任务会非常好"，命令行版今天实测"效率非常高，而且生态比较友好"。腾讯的 WorkBody 也试了，"每天额度有限，我处理一个复杂任务，它的额度就没有了"（示例：喂数据让它生成竞品报告，一次就耗光额度）。共同点是"都是全局，只要你给权限，它可以全局管理你的电脑上读取所有的信息"，但"这不够用，量太小了"。由此推出个人使用的高性价比组合："如果要用这种全局去开发一些小任务或者脚本，推荐就用 DeepSeek 的 V4 模型 API，加上 Claude Code"，"300 块钱的话够你用，只要不是天天玩，够用一个月、两个月是没问题的"。因果链：模型/平台每日额度与单价约束 → 复杂一次性任务用 GPT 5.6/Codex、试水用 WorkBody → 高频个人自动化任务用 DeepSeek V4 API + Claude Code 的便宜组合 → 按任务价值分配昂贵的额度。

### 🔖 [求职方法论] AI 定时任务自动化：给全局权限，让 AI 每天循环替你搜岗位、抓信息、发到你手上

把"全局 AI"当成无人值守的自动化巡检员。逻辑链：只要给 AI 全局权限，它可以"全局管理你的电脑上读取所有的信息"；进一步可以"定时去查岗位，让它去搜各种 BOSS 上的岗位"，并且"它自己去网上去找一些开源的代码，自己再部署到本地，成为一个定时任务"；"你只要打开，它每天都会循环地去跑，你在意的网站、你在意的一些信息，把你收集起来，发送到你指定的一个地方，减轻我们的很多工作量"。因果链：全局权限 → 定时任务脚本 → 每天循环 → 自动抓取岗位与信息并定点投递 → 求职/情报搜索变成无人值守。这意味着求职的岗位盯梢可以由 AI 7×24 自动完成，人只负责查看推送结果。
