## 技术知识

🧷 **[敏锐关键词] 线性度验证（Precheck）**
是什么：拿到镜头第一步不是调参数，而是验证 sensor gain / SP gain / D gain / 曝光时间与画面亮度是否线性——用可调光光源改亮度、手动调曝光时间和模拟增益（AGAIN）、以画面中心亮度为基准（如 800 lux）逐档验证曝光与亮度的线性关系
为什么值得注意：打破「镜头调试 = 上来就调参数」的直觉，行业标准动作是先验线性度，这是判断 sensor 与曝光链路是否正常的前置门槛
能链接到：ISP 全流程洞察、客观测试项、sensor 调试

🧷 **[敏锐关键词] 钥匙扣色卡**
是什么：客观调参用的 24 色卡 / 灰阶卡可以做成钥匙串大小、绑在手机上随身带
为什么值得注意：打破「专业色卡 = 实验室大图卡」的想象，客观调试工具可以极度轻量化、随身化，极大降低自学者入门门槛
能链接到：客观调参洞察、海思测试模板、个人 DIY 调试

🧷 **[敏锐关键词] 内测 bug 可能不是参数能修的**
是什么：产品内测反馈的「bug」（竞品表现更好）分两类——参数可调 vs 硬件 / 镜头物理缺陷；后者改不了，只能给产品讲清「为什么不能改」
为什么值得注意：打破「图像问题都是调参能解决」的认知，明确 ISP 调参的能力边界 = 硬件天花板，也定义了这类岗位的交付闭环
能链接到：内测反馈洞察、镜头缺陷、供应链硬件限制

🧷 **[敏锐关键词] 去噪算法「赛很多，调不好就假」**
是什么：噪点一旦起来只能靠去噪算法救，但去噪想调得好有很多门道（赛点），调不好画面「很假」
为什么值得注意：打破「去噪 = 一键开滤镜」的想象——去噪是 ISP + 算法端的高难度取舍，且算法救不了硬件短板
能链接到：进光量降本案例、算法与硬件博弈

🧷 **[敏锐关键词] 十几年前的海思测试模板还在用**
是什么：超哥早年做 SP 光学调试时，用海思 2015 / 201x 的客观测试模板改出十几个测试项，拍十几个测试环境，再用软件测分辨率 / MTF；朋友确认这就是「客观测试」（全流程第二步）
为什么值得注意：打破「测试方案年年换代」的想象——客观影像测试方法论非常成熟，近十年的海思模板仍可复用，说明客观指标是行业公共语言、方法论折旧极慢
能链接到：客观调参洞察、ISP 调试技术、测试方法论

## 技术成本

🧷 **[敏锐关键词] 进光量砍到 60% 的降本案例**
是什么：第二代迭代产品为降本，把镜头进光量直接砍到上一代的 60%，结果 SN 噪点极难调——暗部更暗 → 拉 ISO → 噪点去不掉 → 只能靠去噪算法硬补
为什么值得注意：给出「镜头降本 → 算法 / 画质代价」的量化锚点（60%），比抽象讲「便宜没好货」具体得多，是可复用的降本评估模板
能链接到：进光量洞察、去噪算法、技术成本评估

🧷 **[敏锐关键词] 1 英寸底 + 画幅大可以缩放裁剪补偿**
是什么：该公司最大用过 1 英寸底（用在开发中、未上市的新品），手机端小米也有 1 英寸方案；底越大越好但越贵、镜头画幅越大，而画幅大可用后期缩放 / 裁剪 / 裁切补偿
为什么值得注意：给出摄像头行业 sensor 尺寸的现实量级（1 英寸 ≈ 高端上限），并破解「大底 = 必须大画幅、浪费像素」的常规顾虑
能链接到：sensor 选型洞察、CMOS 选型、影像产品定位

## 行业洞察

🧷 **[敏锐关键词] 图像算法不占算力大头，大头是 AI**
是什么：算法工程师不参与选型，因为图像算法占用算力不高；算力大头在 AI——人脸框、运动识别这类
为什么值得注意：打破「画质算法决定 SoC 算力选型」的直觉——选平台（嵌入式）时真正卡算力的是 AI 负载，不是图像处理
能链接到：选型会洞察、平台选型、SoC 算力规划

🧷 **[敏锐关键词] 直播相机的指尖写字功能（运动识别落地）**
是什么：朋友公司直播相机有「用手指在画面 / 空中写字」功能，自研、调用 CPU，已试装、市面有宣传图，是直播场景调研出的真实需求
为什么值得注意：打破「运动识别 = 跑步 / 走路检测」的狭义理解——它可以是手指写字这种细粒度动作，且是真实卖点级的差异化功能
能链接到：AI 算力关键词、直播内容资产、差异化功能调研

🧷 **[敏锐关键词] 早期产品靠拆机竞品 = 跟随战略**
是什么：该公司最初几款产品选型不是自研定义，而是团队自己拆竞品机、做竞品分析报告，然后跟风选型
为什么值得注意：打破「中腰部厂商也做前沿定义」的想象——公开参数根本没有，真实玩法是拆机跟随，选型依据是别人的量产方案
能链接到：选型会洞察、供应链、产品战略

## 求职方法论

🧷 **[敏锐关键词] ISP 调参岗位不涉及选型 = 潜在职业短板**
是什么：朋友对镜头选型、平台选型「都不熟」，其 ISP 岗位只管调参，选型是光学 / 嵌入式工程师的活；超哥点破「这很危险，你要有一个很熟的地方才是优势」
为什么值得注意：打破「做 ISP 就懂镜头全链路」的想象——调参与选型在组织里被切开，长期只调参触不到决策层，是职业护城河的警示信号
能链接到：求职方法论洞察、职业规划、技术选型能力

## 创业认知

🧷 **[敏锐关键词] 融资成则搬家、败则找工作的双轨路径**
是什么：超哥原话：等这边发工资 / 融资了就搬家，融资失败就找工作去；朋友约改天讲「投贷金怎么走」
为什么值得注意：个人创业 / 裸辞状态下的双轨决策逻辑——把「融资成功」和「融资失败」写成两个可执行的后续路径而非孤注一掷，是值得沉淀的决策框架
能链接到：用户画像、求职管道、创业融资
