# 中国公众对自动驾驶安全态度调查报告 — 关键数据

> 来源：人民智库（人民日报旗下）《公众对于无人驾驶汽车的认知与期待调查报告（2025）》；南开大学《中国智能网联汽车社会实验报告（2025）》

## 南开大学《中国智能网联汽车社会实验报告（2025）》

- 发布：中国新一代人工智能发展战略研究院（刘刚教授团队），2025 年 6 月 17 日
- 研究对象：有 L4 级自动驾驶乘坐体验的公众群体（持续 3 年追踪）

| 指标 | 数据 |
|------|------|
| 认为无人驾驶比有人驾驶更安全 | **超过 93%**（创历史新高） |
| 单次乘坐即建立信任 | 超过 80% |
| 重复体验者支持率 | 94% |
| 认为应在公共交通推广自动驾驶 | ~86% |
| 能显著减少交通事故 | ~65% |
| 自认了解自动驾驶技术 | ~50%（2023 年仅 36.2%） |

## 人民智库 2025 年 6 月调查

- 调查时间：2025 年 6 月 12-18 日
- 样本量：10,326 份有效问卷

| 指标 | 数据 |
|------|------|
| 乘坐过无人驾驶汽车 | 57.42% |
| 认可无人驾驶比辅助驾驶更安全 | 75.84% |
| 认同"人是交通中最不确定的因素" | 82.13% |
| 认同"安全不等于零事故" | 86.29% |
| 可以接受无人驾驶汽车 | 53.71%（21.07% 完全接受） |
| 有乘坐体验者接受度更高 | 60.86% |
| 支持国家大力发展无人驾驶 | 66.24% |
| 对未来应用前景有信心 | 64.43% |
| 认为 10 年内可能实现主流替代 | 61.97% |

## 公众最关注的问题

| 问题 | 比例 |
|------|------|
| 交通事故责任划分法律问题 | **30.56%**（最受关注） |
| 数据隐私安全 | 27.81% |
| 智慧城市建设适配 | 25.90% |
| 劳动力转型问题 | 22.30% |

## 最接受自动驾驶替代的场景

| 场景 | 比例 |
|------|------|
| 疲劳/分心驾驶 | 37.42% |
| 路怒/激进驾驶 | 31.85% |
| 酒驾 | 31.01% |
