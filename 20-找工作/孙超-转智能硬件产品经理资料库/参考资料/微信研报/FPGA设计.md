| **题目：室内甲醛智能检测设备** | | | | | | | |
| **一、功能概述**  本系统基于 APduino 开发板，结合 ZE08-CH2O 甲醛传感器和 OLED 显示屏以及文字转语音模块，实现室内甲醛浓度实时监测与超标报警、声音播报功能。系统通过串口获取传感器数据，经 APduino 内部处理器分析处理。当甲醛浓度超过安全阈值（0.08ppm）时，不仅在 OLED 显示屏上显示 “已超标” 警示，还会通过语音模块发出声音报警，并播报当前甲醛测量值。该设备可应用于智能家居、办公环境等场景，为用户提供实时空气质量反馈，预防甲醛污染危害。  现实意义  1、健康守护：甲醛超标严重威胁人体健康，尤其对儿童、孕妇和老人。本系统能实时监测室内甲醛浓度，及时预警，为用户创造安全健康的室内环境。  2、智能家居融合：符合智能家居发展趋势，可融入智能家庭系统，实现自动化控制。如联动空气净化器、新风系统等设备，智能化管理室内空气质量。  3、便捷性提升：0.96 寸 OLED 显示屏提供直观清晰的可视化界面，结合语音播报功能，用户无需复杂操作即可获取甲醛浓度信息，使用方便，提升生活便捷性。  4、预防与治理：及时发现甲醛超标问题，帮助用户采取针对性治理措施，如通风、吸附等，有效降低甲醛浓度，预防潜在健康风险。  **二、软硬件设计方案（包括框图）**  1、PL端设计  ​（1）甲醛传感器UART IP  需求：9600bps 波特率，8N1 格式，实现与 ZE08-CH2O 传感器的指令交互  设计：自主设计 UART IP 核，包含波特率发生器（系统时钟分频为 9600Hz）、数据接收 FIFO、奇偶校验逻辑  支持数据帧格式 "17 00 04 00 XX XX" 的校验与解析，输出原始浓度值至 AXI 总线  测试：ModelSim 仿真验证数据帧接收与解析逻辑  ILA 抓取 UART RX/TX 信号，验证硬件时序匹配  ​（2）OLED控制IP  需求：SPI 驱动 12864 OLED，支持中文字符与动态数据显示  设计：基于 AXI GPIO 定制 IP 核，实现 SPI 主设备功能（4 线制：CLK/CS/DC/SDIN）  集成字库 ROM（存储 GB2312 中文字符点阵），支持 16x16 点阵显示  测试：通过ILA抓取SPI时序波形，验证显示指令发送  实测显示 "甲醛浓度：0.05ppm" 等动态内容   1. 语音模块UART IP   需求：UART 协议控制语音播报（假设波特率 9600bps，8N1 格式）  设计：独立 UART IP 核，支持 TX 发送指令  测试：通过串口助手发送测试指令，验证语音模块响应  上板实测超标时自动触发语音播报  2、PS端软件架构分为四个主要模块：传感器数据读取、浓度解析算法、超标判断逻辑和显示驱动。  ​（1）传感器数据读取 ARM处理器通过AXI总线与UART IP核通信，读取ZE08-CH2O传感器发送的原始数据帧。数据帧格式为"17 00 04 00 XX XX"，其中XX XX为浓度原始值。  ​（2）浓度解析算法z 对原始数据进行温度补偿和单位换算。采用公式：conc = (raw\_data/66.64)0.08 + 0.05T，其中raw\_data为原始值，T为环境温度。通过滑动平均滤波算法消除传感器波动，确保数据稳定性。  ​（3）超标判断逻辑 将解析后的浓度值与国标阈值0.08mg/m³（即66.64ppb）进行比较。若浓度超标，则触发报警标志位；否则更新当前浓度值。  ​（4）显示驱动 根据超标判断结果，通过AXI总线向OLED控制IP发送SPI指令。显示内容为：甲醛浓度:“”；状态：“”。  （5）语音驱动模块  超标时通过 AXI 总线向语音 UART IP 核写入指令（如 0xAA 0x02）。   1. 设计框图   ![未命名文件](data:image/jpeg;base64...)  **三、所采用的平台及模块**  1.
