# 机器人激光雷达技术选型对比（扫地机/割草机/配送机器人）

> 来源：CSDN 技术社区选型指南（2025 年版）、各厂商产品页

## 五大技术原理

| 技术 | 原理 | 光源 | 典型距离 |
|------|------|------|---------|
| 三角测距 | 几何相似三角形，CMOS 测光斑偏移 | EEL/VCSEL 点激光 | 0.05-5m |
| ToF（iToF） | 相位差间接计算飞行时间 | VCSEL + 面阵 | 0.1-10m |
| dToF | 窄脉冲直接计时飞行时间 | 多结 VCSEL + SPAD 阵列 | 0.1-30m+ |
| 线激光（结构光） | 编码线图案形变推算深度 | VCSEL/EEL 线模组 + 红外相机 | 0.05-3m |
| LiDAR（机械/固态） | 360° 旋转或固态扫描获取点云 | 多种 + APD/SPAD | 0.1-25m+ |

## 扫地机感知架构

```
导航/建图 SLAM → 顶部 LiDAR（TOF/dToF） 或三角测距雷达
前方避障/3D 感知 → 线激光 + dToF 面阵 + 双目视觉
近距/悬崖检测 → 红外 PSD / 三角测距
沿边/贴墙 → 红外对管 / 超声波
```

## 五大趋势

1. **dToF 替代 iToF**：多结 VCSEL（效率 56%）+ SPAD 阵列，成本接近传统 iToF
2. **VCSEL 替代 EEL**：温漂仅 EEL 的 1/5，可靠性更高
3. **双线激光成标配**：VCSEL 线激光模组量产成本已降至 ¥50 以内
4. **机械→固态**：Roborock Saros 率先采用固态 LiDAR
5. **多模态融合**：dToF + 线激光 + RGB + AI 成旗舰标配
