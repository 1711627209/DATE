## 一、西湖集团马术场馆（录音1/3）

### 场馆定位与硬件配置

- **行业地位**: 国内排名第二、大湾区排名第一的马术场馆，仅次于上海九市，拥有"世界第五"行业头衔
- **核心设施**:
  - 国内第二家专业马医院（四层马房结构，三层马舍+底层马医院）
  - 全部空调马房（非仅有空调设备，而是真正恒温控制）
  - 两块场地沙子采购总报价达8000余万元
  - 配套：独立酒窖、雪茄吧、地下停车场
  - 室内馆挑高充足、通风良好
- **运营主体**: 深圳西湖集团（国企改制企业）代运营政府场地，集团主业涵盖出租车、大巴、金融、房地产，员工2万+

### 运营逻辑

- **收益属性**: 场馆本身处于亏损状态，不追求经济收益，核心功能为集团高端客户招待载体 + 承接政府闲置场馆运营（政企合作政治价值）
- **保证金**: 年运营保证金2000万元，普通俱乐部无承接能力
- **日常成本**: 两台洒水车日耗水60吨；马工月薪约30万元
- **赛事成本**: 承办一场正规马术赛事（2天）基础成本约100万元+（含人员、中马协申请、场地租金、赛事组），赛事本身不盈利

### 定价体系

| 项目 | 价格 |
|------|------|
| 场地包场（单日） | 10万 / 15万 / 30万（不同规格） |
| 品牌商拍（半天） | 4-6万元 |
| 马匹使用 | 1000元/小时（对比景区200元/天） |
| 单节课程（邻近竞品马场） | 600-1000元 |
| 高净值客户年消费 | 税后50-60万元级别 |

### 获客渠道

- **原则**: 不做公开市场宣传，无对外PR动作
- **渠道**: 影视剧组、建筑公司、保险公司、文博会、粤港澳大湾区车展
- **资源分配**: 集团内部将品牌合作资源定向分配给对接顾问
- **关键洞察**: "古代是马，近代是车"——马术与汽车/奢侈品品牌天然契合（爱马仕起家卖马鞍、POLO拉夫劳伦等）

### 合作门槛

- 仅承接B端大客户，不承接散客和小体量拍摄
- 普通个人拍摄预算仅1000-2000元，叠加差旅、器材成本后无盈利空间
- 曾有剧组看完场地当天即确定合作，所有行程围绕场馆调整

## 二、光明农场马场（录音2）

### 场馆基本情况

- **性质**: 私人运营小型马场，租赁光明农场场地
- **场地配置**: 2个室内训练场 + 1个室外训练场，配套前台、休息区、小会议室、洗浴区、装备更换区
- **运营模式**: 全预约制，单日最多容纳20-30节课
- **客群**: 年龄3-70岁全覆盖，以初级学员为主

### 客流规律

| 时段 | 客流特点 |
|------|----------|
| 周一至周五 | 零散，人少 |
| 周末（周六日） | 相对人多 |
| 工作日白天 | 极少，今天仅1个客人 |
| 高峰时段 | 上午10点、下午4-5点 |

### 定价与竞争

- **课程定价**: 600元/节（南山水平线，隔壁大马场900-1000元）
- **入场门票**: 40-50元（光明农场入园费，起到筛选作用）
- **主要客源**: 光明农场入园游客转化，散客极少

### 赛事安排

- **频率**: 极少举办，几年可能有一场（取决于老板意愿）
- **原因**: 私人马场以盈利为主，赛事亏损不做

### 合作对接规则（与摄影产品开发方约定）

- 可提供闲置空房间存放设备（约1-2个行李箱体量）及临时办公
- 可提供课程表预约信息，便于匹配学员在场时段
- **禁止主动向学员推销**，仅可通过展板展示，待学员主动咨询
- 学员涉及隐私顾虑，不强推
