## 一、营地官方方法论（卓老师 PPT 框架）

### 4 天节奏
> "这四天也是看系统，训练一下咱们系统化的创业思维，按照它那个节奏走，每一步验证都走齐。"

营地不是纯脑暴，而是**系统性创业思维训练**。每步必须走齐，不是跳步。

### 创痛点到产品的 Pipeline

```
痛点发现（临床文献/AI/信源搜索）
    → 找疼痛感强、急迫的病种（刚需）
        → 围绕病种找临床金标准 & 硬件可检测指标的重合点
            → 看哪些硬件能检测 + 哪些有突发奇想的天才思维能切过去
                → 竞品调研（有没有人做过？）
                    → 脑暴 → 投票 → 定方向
```

**关键原则**：**硬件能检测的指标和临床金标准要有重合。** 这是倪老师发的两页 PPT 的核心里程碑——帮你直接从"什么病痛"跳到"什么传感器能做"。

### 产品经理思维：找真问题

> "围绕一个方向去想，把一个东西挖到极致，真正找到真问题。"

- 不要发散到多个方向，聚焦一个深挖
- "真问题"的标准：用户痛到愿意付钱、市面上没有好方案、技术上有可行性

## 二、讨论中涌现的产品方法论

### 2.1 痛点判断四要素

| 要素 | 例子（青光眼泳镜） | 反例（普通护眼泳镜） |
|------|---------------------|----------------------|
| 够痛吗？ | 🟢 青光眼=慢性致盲，眼压失控=加速失明 | 🔴 普通泳镜压眼→痛感不够 |
| 人群够精准吗？ | 🟢 青光眼患者+高眼压人群+要游泳 | 🔴 所有人 |
| 有替代方案吗？ | 🟢 小红书/淘宝几乎无产品，只有"选大框"建议 | 🔴 忍忍就过去了 |
| 用户愿意付费吗？ | 🟢 青光眼患者有治疗焦虑（"可能瞎"） | 🔴 不买也行 |

**来自张书的关键洞察**：
> "这个问题相当于大家不知道可以有更好的解决方案。或者说这个痛点他们就这样忍着了。一定要有一个好的产品出现，你才知道这个问题才是可以解决的。"

**隐含的产品逻辑**：**隐性痛点需要产品来唤醒**——苹果 iPhone 之前没人知道自己需要智能手机。这不是验证需求，是创造需求。

### 2.2 产品定义 vs 产品交付的两个鸿沟

何总（卓驭面试）说过，**"做产品很容易，产品交付是比较吃经验的"**。这条方法论在营地讨论中反复被验证：

| 阶段 | 营地做了什么 | 还缺什么 |
|------|------------|---------|
| 痛点发现 | 🟢 临床经验 + 小红书验证 + AI搜索 | — |
| 技术方案 | 🟡 半导体制冷/气垫/给药（方向有，未验证） | 论文验证、硬件可行性 |
| 产品形态 | 🟡 泳镜改造方案有雏形 | ID设计、人机工学 |
| 量产交付 | ⬜ 完全未触及 | 供应链、认证、成本 |

### 2.3 "改环境" vs "治标" 的产品哲学

张功博的核心产品直觉：

> "脚气/足癣的本质是真菌细菌滋生环境。除臭喷雾是治标不治本——用药杀了真菌，只要环境还在，它还会再长。我要改变的是环境本身（温度+湿度）。"

**产品启示**：**第一性原理——回到问题发生的根本条件，改变条件而非覆盖症状。**

应用到青光眼泳镜：不是"让泳镜不漏水"（治标），而是"改变封闭空间内的压力环境"（改环境）。

### 2.4 MVP 的分层迭代逻辑

眼压泳镜的技术栈分层（讨论中自然浮现）：
```
v1：物理结构改良（气垫/大框）→ 减少压迫
v2：+ 半导体制冷 → 主动降压
v3：+ 眼压监测 → 闭环反馈
v4：+ 自动释药 → 治疗级
```

**原则**：每个版本必须是可独立交付的完整产品，不是 PPT 概念。给药是"后面迭代出的功能，刚开始不要冲着这个去"（张书）。

### 2.5 "硬件能检测的指标和临床金标准重合"

这是营地官方给的最强加速器。不用自己想"什么传感器能做什么"，而是反过来——**先看病种的临床金标准测什么物理量，再看有没有传感器能测这个量**。

| 病种 | 临床金标准/关键指标 | 可能的传感器 |
|------|-------------------|-------------|
| 青光眼 | 眼压（21mmHg 正常上限） | 角膜反射光学/隐形眼镜压力传感 |
| 糖尿病足 | 足部溃烂程度/溃疡面积 | 水凝胶参数传感（已有智能绷带方案） |
| 足癣/脚气 | 温度+湿度 | 温湿度传感器 |
| 静脉血栓 | 肌肉运动量 | 压力传感器（已有成熟产品） |

## 三、团队协作方法论

### 3.1 脑暴规则

1. **每人最多提供 1 个方向**（控制发散）
2. **投票机制定方向**（民主决策）
3. **"谁的更新颖、谁能说服大家，就按这个方向走"**（逻辑+数据说服，不凭资历）
4. **先聚焦再发散**：围绕一个方向深挖→极致→不要跳

### 3.2 跨学科团队的分工逻辑

> "你们确定好硬件，我去调研硬件方案。你们写方案，技术方案我就帮你调研一下。"

**孙超的模式**——专业分工 + 快速响应：
- 临床背景的人定义场景和需求
- 机械的人做结构
- 孙超做硬件方案调研（不越界、不空谈）
- 清华的人做 IP/市场验证

### 3.3 多项目并行策略

> "我们组出两个项目不就得了。三个方案。联合，不分家。"

**当团队有人对不同方向有热情时**——不要强拉统一，拆成子项目并行跑。营地只有 4 天，多个方向同时验证效率更高，最终选验证结果最好的。

### 3.4 最小阻力社交

> "今天都刚认识啊，新的要死。"

**第一天晚上就能开始高效脑暴的关键**：
- 每个人都有明确的专业标签
- 扁平化、没有组长、没有层级
- 想法直接用"痛点+方案"对撞，不需要破冰

## 四、几个值得记住的产品判断

1. **"你花钱买安慰，买焦虑。而且必须是有用的。"**（孙超）——医疗产品的高溢价来自用户对健康焦虑的付费意愿

2. **"不够痛，换我我就不买。"**（张书）——产品经理的第一标准：你自己愿意付钱吗？

3. **"竞品调研看一下市场上有没有人做的。"**（张功博）——最简单的验证，但大多数人跳过了

4. **"问一下 DeepSeek，最简单的调研。"**（孙超）——AI 是第一天晚上最高效的竞品调研工具

5. **"创新都是反常识的，你根本不懂。"**（张功博）——如果所有人都觉得"这是常识"，就不是创新

6. **"经济资源的不平衡所带来的医疗资源的不平衡是最大的不公平。"**（张功博）——AI 医疗创业的终极 why

## 五、对孙超个人的方法论补丁

你在营地里自然扮演的角色：**"你写方案，我调研硬件方案"**——这是你 Vault 里所有方法论的一个实战验证：

| 你的已有认知 | 营地中的验证 |
|-------------|------------|
| 信息分三层（L1>L2>L3） | 第一时间用 DeepSeek 搜索做 L1 验证 |
| 产业图谱 = 硬件方案弹药库 | TEC 制冷、压力传感、温湿度传感——这些都是你图谱里已有的知识 |
| "PM 要从需求出发定义产品" | 你不是在等别人给需求——你在帮团队判断"这个需求技术上能不能做" |
| 3w2（成就+利他） | 你没有争组长，你主动承担了最硬的活（硬件调研），让其他人发挥临床优势 |

**你在这里的不可替代性**：团队里临床的 3 人 + 生物 1 人 + 机械 1 人——**只有你懂传感器硬件**。你就是倪老师说的"硬件可检测指标和临床金标准重合"的翻译官。

## 六、Lightning Speech 环节补充方法论

> 来源：[[../../00-逐字稿/Lightning-Speech/2026-07-23 科创营-LightningSpeech组队分享 逐字稿|Lightning Speech 逐字稿]]

### 6.1 卓老师的四问产品验证法

卓老师在点评每个 pitch 时反复用的逻辑链：

```
1. 真需求吗？ → "你自己养狗吗？"（用户洞察的前提是自己就是用户或深度接触用户）
2. 有效吗？     → "这东西用完能睡着？""腺苷分泌能出来？"（医学有效性是医疗产品的生命线）
3. 为什么非得这样？ → "为什么非得烧艾草？""为什么加脑机接口？"（追问本质，不被技术包装带偏）
4. 为什么还没人做出来？ → "强大的共识背后，没人做出来的产品一定是有问题的"
```

### 6.2 "强大的共识背后没人做出来的产品一定有问题"

**卓老师的原话**：

> "每年我们都有盲人眼镜的项目，但好像没有人做出来。一般我都理解为——一个强大的共识背后，没人做出来的产品，它一定是有问题的。也许它是有效的，但可能问题不出在产品的有效性上。它可能出在——1700万人，有多少是60岁以上的人？也许这才是这个东西很难去卖出去、商业化的真正问题。你都60岁又盲了，这个东西怎么卖给他？他也不可能去电商。你可能又得研究用户买盲人产品的渠道。"

**这是全场最值钱的一条方法论**——当所有人觉得"这应该有人做"但就是没人做出来时，不是做不出来，是"卖不出去"。去研究用户画像的真实消费行为，而非功能有效性。

### 6.3 假共识 vs 真需求的甄别

Lightning Speech 里暴露的常见陷阱：

| pitch | 假共识信号 | 真需求信号 |
|-------|----------|----------|
| 宠物监测器 | "我想做宠物的"——但自己没养狗 | 卓老师: "真养狗的舍不得给狗戴项圈" |
| 盲人眼镜 | 每年都有这个项目，1731万数据 | 但60%是60岁以上老人，没电商行为 |
| 失眠硬币 | "我就是目标用户"——张功博本人失眠 | 但有效性没验证（腺苷分泌？） |
| 艾灸机器人 | 降成本逻辑成立 | 卓老师: "为什么非得烧艾草？"（没回答本质） |

**判断标准**：如果团队里没有一个人是目标用户的**深度体验者**，这个方向大概率是假共识。

### 6.4 政府行为 vs 创业行为的分界

卓老师对孙超偏远乡村挂号方案的判断：

> "我猜这个东西你最后推导出来的解决方案，它是一个政府行为。"

**判断标准**：
- 需要跨医院信息互通 → 政府行为
- 需要改变分级诊疗流程 → 政府行为
- 需要大规模基础设施 → 政府行为
- 可以在单一场景用硬件/软件解决 → 创业行为

孙超提的是**真问题**，但解决方案的落地路径在体制内。这类 idea 在创业营的价值是**让你看到结构性问题的全貌**，而不是拿来创业。

### 6.5 张功博的 Ende 产品哲学

> "我重新定义失眠这个问题。对于焦虑型人格，他之所以失眠，更多是他不知道如何去结束一天，不知道如何去结束脑子里那些还很多的待办任务，不知道如何去迎接一个明天充满竞争的时代。一个承载，一种社交的货币，让你更好的去结束今天，去拥抱明天。"

**核心**：发现失眠的"未定义维度"——不是生理问题，是**认知闭环问题**。失眠的人缺的不是困意（褪黑素能给），是"今天结束了"的心理仪式。产品不只是功能，是**意义的载体**。

### 6.6 孙超的现场表现分析

| 时刻 | 内容 | 评价 |
|------|------|------|
| 主动 cue 录音习惯 | "开会之前要录音，要保持良好习惯" | 🟢 你在团队里已经建立了"工具和流程"的角色标签 |
| 偏远乡村挂号 pitch | 数据驱动（16.8%）、场景具体（卫生所→县→市）、情感连接（"我来自偏远乡村""端午节回家发现"） | 🟢 全场最有故事感的一个 pitch |
| 被卓老师质疑"政府行为" | 你没有强辩，承认"很难，很小很小" | 🟢 成熟——知道边界 |
| 激光雷达被 cue | "我是做激光雷达的。在cue到我了是吗？" | 🟢 在场域内建立了"你就是硬件传感器的人"的认知 |
