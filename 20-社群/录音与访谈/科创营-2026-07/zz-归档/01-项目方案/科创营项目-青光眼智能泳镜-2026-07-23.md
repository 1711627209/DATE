## 一、项目概述

### 一句话

一款能让青光眼患者安全游泳的智能泳镜——通过微孔透气结构消除负压+大框分散静脉压迫，从根源降压。v2+光学眼压监测，v3+微型气泵主动平衡镜内气压。

### 要解决的问题

青光眼/高眼压人群游泳时，传统竞速泳镜的硅胶负压设计导致眼压升高约 **9 mmHg**，加上水下憋气带来的额外升高，可能加速青光眼进展——这是一个**未被满足的细分需求**。

### 为什么这个方向值得做

| 判断维度 | 证据 |
|---------|------|
| **真需求吗？** | 🟢 提出者本人是目标用户（医生说不能眼压太高）。小红书上大量青光眼患者问"能不能游泳"，回答永远是"选大框的" |
| **够痛吗？** | 🟢 青光眼=不可逆致盲。眼压失控=加速失明。用户有治疗焦虑（"可能瞎"） |
| **有竞品吗？** | 🟢 几乎为零。淘宝/小红书无专项产品，全是"佩戴技巧"类建议 |
| **市场存在吗？** | 🟢 中国青光眼患者约2000万+高眼压人群。加上海外市场（欧美青光眼患病率更高） |
| **技术可行吗？** | 🟡 结构改良可做（气垫/大框）。半导体制冷需要验证——水下已有水冷环境，可能需要结合其他方案 |

## 四、临床与技术分析

### 青光眼与眼压的关系

| 参数 | 数值 | 来源 |
|------|------|------|
| 正常眼压范围 | 10-21 mmHg | 临床金标准 |
| 青光眼危险阈值 | >25 mmHg | 临床共识 |
| 竞速泳镜戴后眼压升高 | **约 7-9 mmHg**（王慧琳与专家对话：论文已证实；组内脑暴：~9 mmHg） | 文献/临床观察 |
| 水下憋气眼压增幅 | 额外升高（Valsalva 效应→静脉压升高→房水排出受阻。具体数值待查） | 王慧琳提出，需验证 |

**关键计算**：一个基础眼压 20 mmHg 的青光眼患者 → 戴泳镜后 27-29 mmHg → 远超安全阈值（>21 mmHg）。40 分钟持续高压 = 对视神经的一次有损打击。

### 眼压升高的机制（专家验证后确认）

| 原因 | 机理 | 如何应对 |
|------|------|---------|
| **负压吸附**（原因一） | 泳镜硅胶圈产生负压→眶周静脉受压→静脉压升高→房水流出受阻→眼压升高 | 用微孔透气结构替代硅胶圈 → 消除负压 → 微型气泵调节镜内气压 |
| **硅胶压迫静脉回流**（原因二） | 硅胶圈物理压迫眶周血管→静脉回流受阻。这一点似乎**不可避免** | 把镜框做大（覆盖眉骨到颧骨，不做全面罩式）→ 分散单位面积压迫力 |
| ~~温度因素~~ | ~~封闭空间温度升高→房水生成增加~~ | 已被林业和王慧琳联合排除——水下已有水冷环境，不是主要因素 |

### 现有眼压监测方案

| 方案 | 成熟度 | 缺点 |
|------|:------:|------|
| 隐形眼镜压力传感器 | 国外已有 | 戴隐形+游泳=伤眼睛 |
| 光学角膜反射式 | **实验室已验证**（王慧琳：有论文、专利） | 需集成到泳镜；运动状态精度待确认 |
| 医院喷气式眼压计 | 成熟 | 不是穿戴设备 |

### 现有眼压干预方案

| 方案 | 可行吗 | 备注 |
|------|:------:|------|
| 气垫式镜圈（替代硅胶负压） | 🟢 最可行 | 加大眼眶覆盖面积→分散压力→减少眼球压迫。对应"原因二：硅胶压迫" |
| 微孔透气结构 | 🟢 可行 | 用 Gore-Tex 类防水透气膜替代硅胶圈 → 消除负压吸附。对应"原因一：负压吸附" |
| 微型气泵（主动气压平衡） | 🟡 实验室已验证（王慧琳：有论文、专利） | 传感器发现眼压升高趋势→泵自动调节镜内气压。水下密封+静音+功耗待验证 |
| 半导体制冷（TEC） | 🔴 已排除 | 水下已有水冷环境，温度不是主因 |
| 水下气泵（主动气压平衡） | 🟡 技术较复杂 | 当检测到境内气压升高→自动与外界交换。静音是关键 |
| 微电流释药 | 🔴 药物监管 | 营地老师建议"最好不要做药物" |
| 自动释药 | 🔴 药物+迭代 | 张书建议"给药是后面迭代的功能，刚开始不要冲着这个去" |
| 🆕 日常物理降压眼罩 | 🟢 专家提示方向 | 把泳镜的物理降压原理剥离到日常可穿戴形态——市场从"游泳的青光眼"→"所有青光眼" |

## 五、产品定义 v0.2（专家验证后更新）

### 机理三段论（专家已确认）

```
原因一（负压吸附）→ 微孔透气结构消除负压
原因二（硅胶压迫静脉回流）→ 大框分散压迫
     ↓
传感器检测到眼压仍升高 → 微型气泵主动调镜内气压
     ↓
三合一闭环 = 非负压佩戴 + 水下眼压趋势监测 + 微型泵主动降压
```

> 三项关键技术均有已有论文/专利支撑，但未集成到产品中。（王慧琳对专家的陈述）

### MVP（当前营期目标——Day 2-4）

```
v1: 物理结构改良（纯结构，零电子）
  - 微孔透气膜替代硅胶圈 → 消除负压吸附
  - 大框（覆盖眉骨至颧骨）→ 分散静脉压迫
  - 不依赖电子元件 → 零门槛 + 零安全风险
  - 目标：实测证明"v1 能把升压从 7mmHg 降到 2-3mmHg"
```

### 迭代路线（专家验证后更新）

```
v1: 大框微孔透气泳镜（纯结构）→ 实测降眼压效果
    ↓ 如果 v1 能把升压从 7mmHg 降到 2-3mmHg
v2: + 光学角膜反射式眼压监测 → 知道"现在多少"
    ↓ 如果精度达标（运动状态误差 <3mmHg）
v3: + 微型气泵主动气压平衡 → 知道+自动干预
    ↓
v4: 日常物理降压眼罩 → 市场从"游泳的青光眼"→"所有青光眼"
```

> **原则**：每个版本必须是可独立交付的完整产品。v1 零电子 = 最快路径。电子功能在 v2/v3 逐步加入，不要一开始就三合一。

### 竞品分析（初步）

| 竞品 | 类型 | 与本品的区别 |
|------|------|------------|
| 智能泳镜（AR显示） | 心率/配速/距离 | 不解决眼压问题 |
| 大框泳镜 | 物理减压 | 没有主动平衡机制，只是被动减少压迫 |
| 降眼压药物 | 药物干预 | 不能预防游泳时的瞬时升高 |
| **本品** | 专项眼压干预 | 唯一针对"青光眼+游泳"场景的产品 |

### 产品名字（初步）

**"青蛙眼"**（王慧琳提议，琅琊口）——青光眼+游泳=青蛙眼。有记忆点。

## 六、商业模式

### 对标参考（来自姚总的分享）

> "先做消费级，不拿证。在宣传口径上不要说自己是治疗型的。海外基本都这么做。"

- 不走医疗器械认证路径（至少MVP阶段不走）
- 定位：**消费级健康硬件**（类似Oura指环，估值110亿美金，没拿证）
- 宣称口径：帮助青光眼人群**更舒适地游泳**，而非"治疗青光眼"

### 可能的商业化路径

| 路径 | 逻辑 |
|------|------|
| **toC电商** | 小红书/淘宝——目标用户已经在上面搜"青光眼泳镜"了 |
| **眼科医生推荐** | 跟青光眼专科门诊合作——医生给患者建议"游泳时可以试试这个" |
| **商保合作** | 青光眼=长期慢病，商保有动力做健康管理增值服务 |
| **海外市场** | 欧美青光眼患病率更高+游泳文化更普及+支付能力更强 |

### 支付方思考（姚总框架）

> "产品再好，没人买单=白做。商保是toC之外最快起量的路径。"

青光眼人群有明确的健康焦虑（怕瞎），付费意愿强。参考李总框架：**"花钱买焦虑，而且必须是有用的"**。

## 八、风险评估

| 风险 | 等级 | 专家验证后的最新判断 |
