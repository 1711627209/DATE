## 一、一句话

一条能包裹在小腿上、通过间歇式滚动按摩模仿肌肉运动的智能裹带——让术后卧床患者的腿部肌肉"被动运动"，预防血栓夺命。

---

## 二、临床背景

### DVT（深静脉血栓）的致死链

```
术后长期卧床不动
    → 下肢肌肉不收缩 → 静脉血液淤滞
        → 血栓形成（DVT）
            → 血栓脱落 → 循环到肺 → 肺栓塞（PE）
                → 🔴 猝死
```

这是**术后最凶险的并发症之一**。不是"不舒服"——是"突然死亡"。完全符合姚总的刚需标准："不做管理会不会马上死？"

### 为什么要解决这个

| 参数 | 数据 |
|------|------|
| 术后卧床患者DVT发生率 | 骨科大手术（髋/膝置换）未预防者 40-60% |
| 肺栓塞死亡率 | 未治疗的PE死亡率 ~30% |
| 每年手术量 | 中国每年骨科手术超 500 万台 + 心脏搭桥等 |
| 现有预防手段 | 间歇充气加压装置（IPC）、梯度压力袜（GCS）、抗凝药物 |

### 现有方案的缺陷

| 现有方案 | 原理 | 缺点 |
|---------|------|------|
| 间歇充气加压装置（IPC） | 气囊充放气挤压腿部 | 大、重、贵、有线、只能在医院用 |
| 梯度压力袜（弹力袜） | 被动施压 | 穿脱困难、压力不均匀、不舒服 |
| 抗凝药物 | 药物防凝 | 有出血风险、术后可能禁忌 |
| **本品设想** | 滚动按摩仪改造成包裹形态 | 轻便、可居家用、无药物副作用 |

## 三、六步框架验证

### Step 1: 挖痛点 — 到底谁痛？

**用户**：
```
人物：张阿姨，68岁，刚做完髋关节置换手术
场景：术后第2天，医嘱"卧床一周"。护士给套上了气压泵——又大又吵，管子拖在地上。她想翻个身都不方便。
困境：她知道不动会得血栓。气压泵太难受了，而且只有住院期间才有。出院后呢？回家后呢？
现行方案：住院时被动用IPC（不舒服），出院后医生只说"尽量多活动"——但刚做完手术的老人根本不敢动
后果：如果得了DVT再并发肺栓塞——30%死亡率。比青光眼致盲更快。
```

**这个方向的根本优势**：
- DVT→PE 是会马上死的事。比足癣（痒）、比血糖（慢）都更符合"刚需"
- 它跟姚总投的 PCI 术后管理是同一个逻辑：**不做管理 = 死亡/残疾**。用户依从性天然高
- 王慧琳作为临床医学生，对术后并发症有第一手的认知

**判断**：
- 团队里有人是这个用户吗？→ 🟡 没有患者本人。但王慧琳是医学生，看过术后病人
- 不做会怎样？→ 🟢🟢🟢 血栓→肺栓塞→猝死。**比青光眼泳镜更刚需**

### Step 2: 选场景

| 场景 | 风险 | 时长 | 产品需求 |
|------|:--:|:--:|------|
| 术后住院期间 | 🟢🟢🟢 最高 | 3-7天 | 替代IPC——更轻、更安静、更舒服 |
| 出院后居家康复 | 🟢🟢🟢 | 1-4周 | **这是最大空白——出院后就没人管了** |
| 长期卧床（偏瘫/失能） | 🟢🟢 | 数月-数年 | 长期护理险覆盖 |

**核心切入场景**：术后住院+出院后居家——目前 IPC 只覆盖住院期间，出院后没有连续方案。

### Step 3: 定指标

| 临床目标 | 可测物理量 | 传感器 |
|---------|----------|--------|
| 肌肉被间歇式挤压（模拟行走时的肌肉泵效应） | 压力（N/cm²）+ 频率（次/min） | 薄膜压力传感器 |
| 压到位了吗？ | 压力反馈 | 同上 |
| 使用时长 | 时间戳 | MCU 内部时钟 |
| 用户依从性 | 佩戴时长、是否在正确位置 | 加速度计 / IMU |

### Step 4: 选硬件

**产品形态**：从"滚动按摩仪"改造 → 包裹式滚压裹带

张功博的 key insight：
> "我今天试那个滚智能滚动按摩仪——把它的原本头部压力，现在变成一个包裹形态，你觉得会不会好？"

**核心创新**：把市面上已有的"智能滚动按摩仪"（通常是小手持式、用在肩颈/头部）的机械结构，**重新封装为包裹腿部的形态**。不是从零造轮子——是形态迁移。

| 参数 | 设计 |
|------|------|
| 形态 | 柔性裹带（Velcro搭扣）+ 内置 2-3 个滚动按摩球 |
| 驱动 | 微型直流减速电机，每个球独立驱动 |
| 压力范围 | 40-50 mmHg（临床公认的有效压力区间） |
| 节律 | 间歇式：压 10s → 松 5s → 下一个球压 10s，模拟行走时肌肉泵的蠕动波 |
| 电池 | 可充电锂电池（18650×2）——够用 8h（一晚） |
| 控制 | MCU + 蓝牙 → APP 设置压力和频率 + 使用记录 |
| 重量 | 目标 < 500g（对比 IPC 设备通常 3-5kg） |
| 尺寸 | 折叠后能塞进背包——"出院带回家" |

**孙超的硬件判断**：
- 核心机械结构市面上已有（手持滚珠按摩仪）——不需要从零研发滚动机构
- 加压力传感器做闭环反馈——"压到了吗？压到多少了？"
- BOM 粗略：减速电机×3（~45元）+ 压力传感器×3（~30元）+ MCU+蓝牙（~20元）+ 电池（~30元）+ 裹带+结构件（~50元）= **~175元 BOM**，售价 599-899 元

### Step 5: 验市场

**竞品**：

| 竞品 | 形态 | 价格 | 为什么没解决 |
|------|------|------|------------|
| IPC 气压泵 | 大型设备，气囊+泵+管子 | 医院采购价数千 | 只能在医院用、有噪音、不舒服 |
| 梯度压力袜 | 弹力袜 | 几十到几百 | 被动、不模仿运动节律 |
| 手持按摩仪（肩颈） | 小手持式 | 100-300元 | 没有腿部包裹形态——这是产品迁移的机会 |
| 腿部气压按摩器（家用） | 气囊式 | 300-800元 | 有，但大多没有临床级压力控制和节律——跟医院IPC不是一回事 |
| **本品** | 包裹式滚动按摩 | 目标599-899元 | 轻便+可居家+医院级的压力控制+节律 |

**对标案例**（姚总分享）：
> PCI 术后管理公司——集采后支架从几千→几百，术后管理没人做。他们做了血压计+小程序+护士链接，跑出来了。

**类比**：IPC 是医院的，出院后就没人管了。你做的就是"出院后的 PCI 管理"——把医疗级预防从医院延伸到家里。

### Step 6: 出原型

**v1 MVP（营地4天可做）**：
- 拿一个市售手持滚动按摩仪
- 拆开，取出滚珠机构+电机
- 缝一个 Velcro 裹带（可用弹力绷带改造）
- 3D打印滚珠支架，固定在裹带内侧
- Arduino + 压力传感器 → APP 显示压力和节律
- **不是好看的东西，但能证明"滚动+包裹+压力控制"的技术可行性**

**v2**：
- 定制柔性 PCB + 薄型电机
- 医用级硅胶包裹层（可擦拭消毒）
- APP 预设"骨科术后模式""心脏搭桥后模式"等不同节律方案

**v3**：
- 拿二类医疗器械证
- 进院——住院期间医生开方→出院带回继续用
- 对接商保——护理险/LTC险可报销

## 四、致命风险评估

| 风险 | 等级 | 应对 |
|------|:--:|------|
| 已有成熟竞品（IPC）——赛道不是蓝海 | 🔴 高 | 不打院内（IPC的地盘），打**院后居家**——IPC出不了院，你能 |

## 五、商业模式

| 路径 | 逻辑 |
|------|------|
| 医生推荐 | 骨科/心外科医生在患者出院时推荐——"回家后继续用这个，预防血栓" |
| 医院采购（后期拿证） | 替代IPC，降低医院设备成本（IPC一台几千，本品几百） |
| 商保/LTC险 | 长护险（今年国家推的新险种）——失能半失能老人的长期卧床预防 |
| toC | 天猫/京东医疗器械类目——术后患者家属主动搜索 |

**对标**：姚总提到的 PCI 术后管理——硬件（血压计）+ 软件（小程序）+ 服务（护士链接）。本品也是硬件（按摩裹带）+ 软件（APP 压力/节律控制）+ 服务（术后康复指导）。

## 六、为什么被排在第四

| 优势 | 劣势 |
|------|------|
| 🟢 DVT→PE = 会马上死，比青光眼更刚需 | 🔴 已有成熟临床方案（IPC）——赛道不蓝 |
| 🟢 跟姚总 PCI 案例完全同逻辑——赛道已验证 | 🔴 机械结构+压力控制+可靠性——4天做不了完整原型 |
| 🟢 王慧琳有临床背景+张功博有按摩仪直觉 | 🔴 团队没有机械电子工程的深度背景（张书是船舶结构，不是电机） |
| 🟡 消费级→医疗级的升级路径清晰 | 🟡 需要更长的时间验证临床有效性 |

**排在第四的原因**：方向是对的（刚需），但营地4天能做出来的东西有限。青光眼泳镜 v1 只需要结构改良——零电子元件；这个方向 v1 就需要电机+压力传感+控制。**工程复杂度高一档。**
