## 一、一句话

一条能主动保持低温干爽环境的内裤——为备孕男性和发育期青少年守住生殖健康的第一道防线。

---

## 二、六步框架验证

### Step 1: 挖痛点 — 到底谁痛？

**用户一：备孕期宝爸**
```
人物：小李，32岁，结婚3年，正在备孕
场景：去医院做精液常规，医生说"活性偏低，注意不要久坐，保持凉爽"
困境：知道低温对质量有好处（临床认证，温度比体温低2°C），但穿什么内裤都一样——夏天出汗、久坐办公、开车通勤，裆部温度从来没低过
现行方案：穿宽松内裤+少坐+偶尔冷水冲——很不方便，冬天更难受
付费意愿：🟢🟢🟢 "花钱买焦虑"（孙超原话）——备孕家庭已经花了成千上万，一条几百块的内裤完全愿意
```

**用户二：发育期青少年**
```
人物：小明，14岁，初中生
场景：正处于青春期发育关键阶段
困境：家长知道生殖系统发育跟温度环境有关，但不知道怎么办。买普通纯棉内裤已经是最"讲究"的做法了
现行方案：无——根本没人做这个
付费者：家长（宝妈付费意愿 > 宝爸自己买）
```

**判断**：
- 团队里有人是这个用户吗？→ 🟡 孙超不是——但身边有备孕朋友，观察过需求。需要Day 2找真实用户聊
- 不做会怎样？→ 不会马上死，但长期影响生殖能力。介于刚需和痒点之间——**比糖尿病管理更有紧迫感，但不如青光眼失明的恐惧**

### Step 2: 选场景 — 在哪个时刻？

| 场景 | 温度暴露风险 | 时长 | 切入优先级 |
|------|:--:|:--:|:--:|
| 夜间睡眠 | 中等（被子+体温） | 7-8h | 🟢🟢 最长连续时段 |
| 白天久坐办公 | 🟢🟢🟢 最高 | 8-10h | 🟢🟢🟢 核心场景 |
| 开车通勤 | 🟢🟢 | 1-2h | 🟡 |
| 运动（跑步/健身） | 🟢🟢🟢 | 1h | 🟡 紧身运动服更糟 |

**MVP切入场景**：白天穿着（全天候）。不是"某个时刻用一下"——是**穿了就起效**。

### Step 3: 定指标 — 测什么物理量？

| 临床原则 | 可测物理量 | 传感器 |
|---------|----------|--------|
| 温度比体温低 2°C（≈34-35°C 是适宜温区） | 裆部微环境温度 | 微型NTC热敏电阻 / 数字温度传感器 |
| 干燥（湿度越低越好） | 裆部微环境湿度 | 微型湿度传感器 |
| 持续时间（累计低温干爽时长） | 时间戳 | MCU内部时钟 |

**关键数据**（王慧琳在讨论中提供）：
> 几十年前精液常规：活性 > 80% 正常。现在：> 4% 正常。
> 原因：环境污染、微塑料、生活习惯。温度是少数可控变量之一。

**传感器选型**：
- 温度：SHT30（温湿度一体，I2C接口，尺寸 2.5×2.5mm，~5元）
- 成本极低，功耗极低，可洗（需要封装在防水模组内）

### Step 4: 选硬件 — 做成什么形态？

**核心矛盾**：内裤需要频繁清洗——电子元件和电池怎么办？

**三个方案**：

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| **A: 可拆卸模组** | 温湿度传感模组+电池+蓝牙，夹在内裤外侧口袋 | 可拆卸，内裤随便洗 | 用户需要记得装上——"需要记得"=流失 |
| **B: 结构型（非电子）** | 不用电子元件——用特殊织物+通风结构+相变材料（PCM）被动降温 | 零维护、零充电、可洗 | 无法监测数据，只是"环境改良" |
| **C: 模组+内裤一体** | 模组嵌入式，可机洗（防水封装IP68），无线充电 | 体验最好 | 成本高，NRE大 |

**MVP建议：方案B（结构型）或方案A（可拆卸）**

**对标参考**：
- Oura指环——被动佩戴就收集数据，不需要"记得用"
- 秦超提到的"反向版本"——声波避孕内裤已获融资，说明资本市场认可"生殖健康+穿戴"这个品类

### Step 5: 验市场 — 有没有人付钱？

**竞品快速扫描**：

| 竞品 | 类型 | 现状 |
|------|------|------|
| 声波避孕内裤 | 反向版本（避孕） | 秦超说已有融资案例 |
| 降温坐垫/凉席 | 久坐场景 | 有，但不针对生殖健康 |
| 宽松纯棉内裤 | 物理改良 | "最讲究的做法也只是换一条纯棉内裤"——没有科技含量 |
| **本品** | 主动降温干爽 | 🟢 正向备孕方向未见竞品 |

**付费意愿验证**（需要Day 2去做）：
- 找3个备孕男性/宝妈问：如果有一条内裤能保持裆部温度低2°C，你愿意花多少钱？
- 在亲子/备孕类小红书帖子下看评论——有没有人在找这类产品？

### Step 6: 出原型

**v1 MVP（营地4天可做）**：
- 找一条市售内裤
- 缝一个小口袋（外侧）
- 塞入温湿度传感器模组+3D打印防水壳+蓝牙模块
- APP显示实时温湿度+"已保持低温X小时"

**v2**：
- 加入相变材料（PCM，相变温度~28°C）
- 加入微型风扇（1cm 离心风扇，静音）

**v3**：
- 防水封装 → 可机洗
- 无线充电底座
- AI分析温湿度趋势 → 给出"今天适宜备孕"等建议

## 三、致命风险评估

| 风险 | 等级 | 应对 |
|------|:--:|------|
| 产品形态敏感——"笑不出来" | 🔴 高 | 品牌定位必须严肃+医疗感（不是情趣产品）。宣传语用"生殖健康"不用"内裤" |
| 团队没有纺织/服装背景 | 🟡 中 | v1从市售内裤改造，不做面料研发 |
| "不够刚需"——跟糖尿病管理一样，今天不做不会马上死 | 🔴 高 | 但备孕是**阶段性刚需**——备孕期6个月到1年，这段时间内非常焦虑。跟Oura指环类比：所有人睡觉都戴手表，但只有焦虑的人戴Oura |
| 用户需要"记得装模组" | 🟡 中 | 方案B（结构型）零操作门槛。方案A需要养成习惯 |
| 清洗问题 | 🟡 中 | v1用可拆卸方案；v3做IP68防水 |
| 市场规模？ | 🟡 | 需验证：备孕人群+发育期青少年父母——这两个群体的付费意愿和人数 |

| 路径 | 逻辑 |

| toC 电商 | 小红书/抖音——备孕/育儿类内容精准投放。目标用户：备孕宝妈（为老公买） |

## 六、孙超的硬件方案（预调研）

你能直接回答的问题：

| 问题 | 答案 |
|------|------|
| 温湿度传感器用什么？ | SHT30/SHT31（I2C，微型，温湿度一体，5-10元） |
| 蓝牙模块？ | nRF52832模组，~15元 |
| 电池？ | 钮扣电池CR2032（3V，~200mAh），或用微型锂电 |
| 降温怎么做？ | 方案一：相变材料（PCM，石蜡类，相变温度~28°C）；方案二：微型离心风扇（1cm直径，静音） |
| 防水？ | 模组用硅胶密封+纳米涂层。内裤本身不需要电子元件——模组是可拆卸的 |
| BOM粗略？ | 温度传感模组 ~30元 + 蓝牙 ~15元 + 电池 ~5元 + 内裤 ~20元 = **~70元 BOM**，售价299-499元，毛利率70%+ |
| 能洗吗？ | v1模组拆卸→机洗内裤；v3 IP68防水封装→整体机洗 |
