# 多功能乳腺保健仪 — 哺乳期乳腺炎预防与日常保健 — v0.5

> **一句话**：一款针对产后哺乳期女性，通过可调节支架+水疗自适应贴合技术，在居家场景下释放双手完成乳腺冷敷/热敷/按摩保健的设备——填补临床指南确认的"冷敷有效但缺乏高质量证据和标准化设备"的空白。把"生菜叶子敷乳房"变成历史。

## 一、为什么是这个方向

### 痛点被多位导师验证为"真需求+强刚需"

| 验证来源 | 验证结论 |
|---------|---------|
| **刘霞主任**（山东省立医院护理部） | PPT完整数据+临床经验证实发病率2-33%，现有方案极差 |
| **深大老师**（医疗器械方向） | "这是一个很好的方向，消费者一定会为此买单" |
| **企业导师**（医疗信息化） | "人群非常合适" |

### 核心理由

1. **痛点够痛**："分娩的痛是伴随对新生命的期待，这个只有痛" — 刘霞主任
2. **人群够大**：每个生育的母亲都是潜在用户（中国每年~900万新生儿）
3. **现有方案极差**：生菜叶子+冰箱+擀面杖——但凡有个产品都是升级
4. **消费意愿强**：导师判断"一定会买单"
5. **可出海**：欧美没有坐月子传统，对舒适类产品付费意愿更强

## 二、临床数据

| 数据 | 数值 | 来源 | 证据等级 |
|------|------|------|:--:|
| 哺乳期乳腺炎全球发病率 | **3%-33%** | 中华医学会外科学分会乳腺外科学组·2025 临床实践指南（引 WHO 2000 + ABM 2022） | 国家级指南 |
| 发病率峰值窗口 | 产后**3～4周** | 2025 指南 | 国家级指南 |
| 推荐治疗方法 | 持续母乳喂养/规律排乳（Ⅰ类/A级）；抗生素（24-48h未缓解时，Ⅰ类/A级） | 2025 指南 表3 | GRADE 分级 |
| 冷敷治疗 | "哺乳后局部冷敷亦可减轻胀痛，但相关证据质量有限"（指南原文） | 2025 指南 3.1节 | ⚠️ 指南承认有效但缺高质量证据 |
| 乳汁淤积→乳腺炎进展 | 规范疏通**48小时**内缓解，不发展为感染 | 刘霞主任PPT（临床经验） | 专家共识 |
| 发热程度 | 常≥**38.5℃**，伴畏寒寒战、头痛、肌肉酸痛 | 刘霞主任PPT | 专家共识 |
| 恶化路径 | 乳汁淤积→急性乳腺炎→**乳腺脓肿** | 2025 指南 + 刘霞主任PPT | 国家级指南 |
| 中国每年新生儿 | ~**900万** | 国家统计局 | 官方统计 |
| 每年新发患者（估算） | 至少 **27万-297万** | 发病率×900万 | 推算 |

### 冷敷证据缺口 ⭐ 核心论据

指南已明确承认冷敷有效，但用了"证据质量有限"——翻译成人话：

> **"冷敷对哺乳期胀痛确实有效，这是共识。但至今没有标准化的冷敷设备，也没有高质量的 RCT 临床证据来证明它好多少、怎么用最好。"**

这个缺口正是我们的切入点：
- ✅ 有效不存疑（指南已确认）
- ✅ 没有标准化设备（只有生菜叶子+冰箱）
- ✅ 没有高质量临床证据（我们可以做——刘霞主任可对接临床验证）
- ✅ 指南级别背书（中华医学会外科学分会，不是一般PPT）

### 非哺乳期乳腺炎（NPM，指南3.2节）

> NPM 病程 9-12 个月，治疗复杂（糖皮质激素、抗分枝杆菌、手术）。与 v1 产品（急性哺乳期干预）关系有限，但 **v3 扩展用户（日常乳腺保健）** 可定位为"辅助康复期的物理舒适护理"。

## 三、用户与场景

### 核心用户画像

**v1 核心用户：** 产后 3-4 周内（峰值窗口）的哺乳期妈妈
**v2 扩展用户：** 产后 0-6 个月哺乳期 + 有乳腺结节/乳腺保健需求的女性（"生气了就乳腺结节"）

### 用户痛点时刻

```
婴儿在旁边哭
乳房突然红肿热痛，硬如石头
38.5°C是起步，经常39°C以上高烧
冰箱里的生菜叶子——要清洗、去梗、擀压、外敷、频繁更换
需要平躺不动→进一步限制活动→增加痛苦
```

### 导师补充洞察

> "母亲最大的问题是**睡觉碎片化**。一会儿要喂奶，一会儿要换尿布，根本没有时间躺着。"

这意味着产品设计必须考虑：
- **操作要极简**（不超过2步）
- **使用时间要灵活**（配合碎片化时间）
- **不能要求"躺下不动30分钟"**

### 现有替代方案

| 方案 | 问题 |
|------|------|
| 生菜叶子冷敷 | 麻烦（清洗/去梗/擀压/更换）+ 效果有限 |
| 土豆切片冷敷 | 同样麻烦 + 频繁更换 |
| 手排/吸奶器排空 | 治标不治本（只排空不消炎） |
| 去医院/诊所 | 费时费力（产后出门困难） |
| **硬扛**（最多） | 恶化风险大，痛苦持续 |

## 四、产品设计 v0.4（团队PPT框架讨论后更新）

### 迭代路径

```
穿戴式内衣（v0.2）
    ↓ 导师反馈：重量限制、功能受限
水疗水囊式·趴卧（v0.3）
    ↓ 团队讨论：趴卧不可行、羞耻感、碎片化时间
马鞍椅+水疗混合形态（v0.4）
    ↓ AI初稿评估：固定姿势不可行、腹部不能挤压、需要多姿势
可调节多功能支架概念（v0.4.1）🆕
    ↓ 下一步：用户访谈验证姿势偏好
```

### v0.4.1 推荐方案：可调节多功能支架 + 水疗

**产品形态**：类似"手机支架"的可调节固定装置 + 水囊模块。不是固定椅子，而是一个**可调节的支架装置**，你可以这么放、那么放——想靠着沙发时拉过来盖在胸前，想半躺着时调节角度让支架支在身体上方。

**核心设计决策（v0.4.1 新增）：**

| 决策 | 原因 |
|------|------|
| **可调节而非固定** | 产后妈妈不能保持一个姿势太久（肌肉僵硬+伤口疼痛）；多姿势=兼容不同时刻的需求 |
| **腹部镂空** | 剖腹产伤口不能挤压 → 支架只覆盖胸部区域，腹部悬空 |
| **"手机支架"式结构** | 灵活拉拽+固定，像高级手机支架一样随意调节角度和位置 |
| **傻瓜式操作** | "坐好→拉过来→按开始"三步以内 |
| **折叠收纳** | 不用时折叠靠墙，材料选轻质高强度（铝合金/碳纤维+织物） |

**产品分级策略（会议中提出）：**

| 版本 | 功能 | 定价 | 目标 |
|------|------|------|------|
| **基础版** | 固定场景，单一姿势，基础冷敷+按摩 | 低（获客） | 让用户先进来 |
| **进阶版** | 可调节支架，多姿势，冷+热+按摩 | 中（主力） | 核心收入 |
| **尊享版** | 全功能 + 药物缓释 + AI监测 | 高（利润） | 高端用户+出海 |

**视觉设计原则：**
- 去医疗器械感：家居风格，不做白色/蓝色冷淡色调
- 去性暗示：不做乳房形状凹陷，不做粉色/紫色女性化过度包装
- 家庭友好：可折叠/可收纳，不当"大件"突兀存在于客厅

**v1 功能层（急性期冷敷+按摩）：**
1. 横向弧条水囊 → 启动时自动充水包裹，自适应贴合各种胸型
2. 温控模块 → 冷敷（急性期降温）/ 热敷（缓解期促进循环）
3. 水压按摩 → 从外向内温和推压，模拟人手乳腺疏通手法
4. 腰部/臀部支撑 → 马鞍椅形态自带腰部肌肉放松（产后久卧肌肉僵硬）

**v2 扩展层：**
5. 药物缓释水囊（耗材）→ 消炎/镇痛药物通过半透膜缓慢渗透
6. 智能监测 → 温度检测+硬结定位
7. AI识别 → 自动识别最佳按摩位置和力度

**v3 出海方向：**
- 欧美无坐月子传统，对舒适类产品付费意愿强
- 命名和外观设计须从 v1 开始考虑国际化

### 竞品差异化

| 维度 | 现有方案（手动/硬质器械） | 我们的方案 |
|------|----------|----------|
| 贴合方式 | 固定尺寸，硬质接触 | ✅ 水囊自适应，柔软贴合 |
| 使用姿势 | 躺平不动 | ✅ 坐/半躺，可同时做其他事 |
| 外观 | 医疗器械感重 | ✅ 家居友好，降低羞耻心 |
| 覆盖功能 | 单一（冷敷 or 按摩） | ✅ 冷/热/按摩一体 |
| 耗材模式 | 无 | ✅ 药物缓释水囊=持续收入 |

### 关键约束（导师+团队讨论）

1. **产后能否坐/半躺？** → 需验证（剖腹产 vs 顺产，分阶段）——但比趴卧可行性高得多
2. **坐月子不接触水** → 水囊有隔膜，不直接接触皮肤
3. **不能太笨重** → 需可折叠/可收纳，家庭友好
4. **保持干燥** → 潮湿环境有感染风险，设计须考虑
5. **操作极简** → 不超过2步：坐下→按开始
6. 🆕 **羞耻心** → 横向弧条 > 两个半圆凹陷；家居风格 > 医疗器械风格
