## 逐字稿

> 这页讲技术实现。
>
> 产品架构非常简单：一块电池，一个升压模块，一颗 MCU，一个模拟开关矩阵，六到八个电极触点，再加一个按键。没了。
>
> 核心原理是经皮穴位电刺激。波形用疏密波——两赫兹密波和十五赫兹疏波交替输出。为什么选这个波形？两点：第一，它有明确的中医临床基础，王进忠 2019 的研究证明疏密波能促进内源性阿片肽释放、改善局部循环；第二，它低频——低频电流组织穿透深，能有效覆盖天泉穴下方神经和血管结构。
>
> 脉宽两百微秒，这是低频 TENS 的标准参数，安全且体感明确。强度从零开始，缓慢爬升到最大五十毫安——用户感受到麻刺感但没有疼痛，自己按耐受度调节。
>
> 关于电极布局。臂环内侧放六到八个电极触点，覆盖天泉穴上下各三厘米的范围。戴上之后，MCU 控制模拟开关，逐个轮询所有电极对之间的皮肤阻抗，自动选出阻抗最低的两点——也就是导电最好的两点——作为刺激输出点。整个过程不到五秒。用户完全不知道"天泉穴"在哪，也不需要知道。
>
> 供电：一块三点七伏锂电池，升压到零到五十伏恒流输出。一次充电跑五到八次治疗，够一个通乳周期。磁吸充电——她不需要对准接口，闭着眼睛放上去就行。
>
> 重量目标八十克以内。臂环戴在胳膊上，不重不过敏。
>
> 监管路径：中国 II 类医疗器械。TENS 品类注册路径成熟，YY/T 0868 标准就在那里。关键的一步是临床试验——证明"电刺激天泉穴能缓解乳汁淤积"。黄丽群 2025 已经用手法做了这个临床研究、拿到了显著性结果，我们在文献层面上有直接支撑。
>
> 我们为什么有信心？因为这个产品不需要任何技术突破。TENS 芯片，有。升压电路，有。阻抗检测，有。柔性电极，有。我们做的就是选型、集成、优化电极布局、把臂环做薄做舒服。从工程角度看，这件事能做。

## 技术参数速查表（备用弹药）

| 参数 | 数值 | 依据/说明 |
|------|------|------|
| 波形 | 疏密波 2/15Hz | 王进忠 2019；低频穿透深、体感可耐受 |
| 脉宽 | 200μs | TENS 低频标准参数 |
| 输出强度 | 0-50mA 可调 | 缓慢递增至用户可耐受 |
| 输出模式 | 恒流 | 防止阻抗变化导致电流突变 |
| 治疗时长 | 20min/次（默认） | 临床常用治疗时长 |
| 电极数 | 6-8 通道 | 覆盖天泉穴 ±3cm |
| 寻穴方式 | 阻抗扫描 + MCU 自动选路 | 轮询所有电极对，选最低阻抗 |
| 供电 | 3.7V 锂电池 → 升压 0-50V | 一次充电 5-8 次治疗 |
| 充电 | 磁吸充电，Type-C 接口 | 零对准，夜间友好 |
| 重量 | <80g | 含电池，臂环佩戴不累 |
| 臂环材质 | 弹性织物 + 硅胶内衬 | 透气、可水洗、无过敏 |
| 耗材 | 可更换凝胶贴片 | 每周更换，卫生+复购 |
| 按钮 | 1 个（开机/开始/停止/关机） | 单击/长按/双击区分操作 |
| 状态指示 | 隐藏式 LED 灯带 | 莫兰迪色织物遮罩，亮灯时可见 |
| 通讯 | BLE 5.0（预留，v2.0 开放） | v1.0 不依赖 App |
| 合规 | 中国 II 类器械 / YY/T 0868-2021 | TENS 品类注册路径成熟 |

## 工程路线图

```

├── 电极布局优化（人体实验，N≥10，测不同体型天泉穴位置分布）

├── 电路板设计 + 打样
├── 臂环结构设计 + 开模
├── 功能样机 3-5 台
└── 内部可用性测试（模拟凌晨场景）
```
