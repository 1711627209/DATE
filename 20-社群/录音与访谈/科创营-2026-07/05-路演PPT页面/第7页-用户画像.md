# 第7页：用户画像 · 凌晨三点的妈妈

## PPT 内容

**主标题**：

> **凌晨三点，她一个人醒着，搜"堵奶怎么办"。**

**上半页 — 用户画像（谁）**：

```
初产妇 · 第一胎 · 产后第 3-4 周 · 中度乳汁淤积

时间：凌晨 2:00-5:00 ← 泌乳高峰，堵奶高发
空间：卧室床上，婴儿在旁边，灯关着，全家在睡
手上：手机（搜"堵奶怎么办"）、吸奶器（试过了，不管用）、温度计（量体温，38.5°C 是线）
她怕的不是疼——是拖成乳腺炎 → 用抗生素 → 停母乳 → "连这件事都做不好，对不起孩子。"
```

**下半页 — 她在搜什么（用户任务）**：

```
当她搜"堵奶硬块怎么办"的时候，她是在问五件事：

1. 能不能让我不那么痛？
   → 现在，不是明天早上。

2. 能不能我自己用？
   → 不用等通乳师，不用叫醒老公。

3. 能不能别碰我乳房？
   → 已经痛到衣服擦过去都受不了。

4. 用了之后，我到底好没好？
   → 硬块在变小还是恶化？什么时候必须去医院？

5. 能不能别打断我的正常哺乳？
   → 她是妈妈，不是病人。她要继续喂母乳。
```

**底部一句**：

> 我们的产品卡在：吸奶器不管用之后、凌晨通乳师来不了之前、体温还没到 38.5°C 的窗口里。

## 逐字稿

> 前面我们讲了数据、讲了文献、讲了迭代。但所有这些东西，最后要落在一个人身上。这个人是谁？
>
> 她不是"产后女性"。不是"哺乳期妈妈"。这些词太大了，大到看不见人。
>
> 她是初产妇，第一胎。产后三到四周，乳腺炎发病率的峰值窗口。凌晨两点到五点之间——泌乳高峰期，也是堵奶最高发的时间。刚喂完夜奶，孩子终于睡着了。她用手一摸——有个硬块。心里咯噔一下。
>
> 你生过孩子就知道这种感觉——不是疼，是害怕。因为你经历过。你知道接下来会怎么样。
>
> 她打开手机。屏幕亮度调到最低，不吵醒孩子。她在搜索框里打上"堵奶硬块怎么办"，然后往下翻——热水敷、吸奶器、通乳师、生菜叶子。没有一个能现在用的。
>
> 吸奶器？刚试了。堵着的地方吸不出来，越吸越疼。通乳师？三百块一次，但凌晨三点没人来。老公在隔壁打呼噜，叫不醒。妈妈群里发了条消息——没人回。大家都睡着。就她一个人醒着。
>
> 冰箱里还放着半颗生菜。不是吃的——是上次堵的时候敷的。化了就换一片，撑到天亮。
>
> 然后她开始搜"乳腺炎是什么症状"。"38 度 5 以上要马上去医院"。她拿出温度计量了一下——还好，没烧。但是心里清楚：如果今天晚上不通，明天可能就烧起来了。
>
> 她怕的不是疼。她已经够疼了。她怕的是发烧。发烧就得去医院。去了医院就得用抗生素。用了抗生素就得停母乳。母乳喂养——这是她当妈妈之后做的第一件事。如果连这件事都坚持不下来——她觉得对不起孩子。
>
> 不是说"她需要一款好产品"。是她需要一样东西——**现在就能用，她能自己操作，不需要碰那个疼得发抖的地方，帮她把硬块通了。** 这样她才能放下手机，天亮之前再睡一会儿。
>
> 我们的产品就是给这个时间点设计的——不是明天早上，不是等通乳师来，是**那个搜索还没出结果的凌晨三点**。
