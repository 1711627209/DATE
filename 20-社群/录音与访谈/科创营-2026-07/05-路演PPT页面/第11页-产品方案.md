# 第11页：产品方案 · 把复杂留给电路，把简单留给用户

## PPT 内容

**主标题**：

> **戴上去。按开始。**

**中央 — 产品形态**：

```
┌─────────────────────────────────────────────┐
│                                             │
│   臂环式 · 多触点自动寻穴 · 去医疗器械感      │
│                                             │
│   ┌─────┐    ┌──────────┐    ┌───────────┐  │
│   │     │    │          │    │           │  │
│   │ 套上 │ →  │ 自动寻穴  │ →  │ 20分钟后   │  │
│   │ 臂环 │    │ 疏密波输出 │    │ 自动停止   │  │
│   │     │    │          │    │           │  │
│   └─────┘    └──────────┘    └───────────┘  │
│                                             │
│   弹性织物臂环 + 6-8 电极位点阵列             │
│   覆盖天泉穴 ±3cm 区域                       │
│   佩戴后自动阻抗扫描 → 轮询 → 选最优两点       │
│                                             │
└─────────────────────────────────────────────┘
```

**底部五个设计决策**：

```
1. 形态：臂环式（非贴片式）——套上就行，零认知负担
2. 定位：多触点阻抗自动寻优——用户永远不需要知道"天泉穴在哪"
3. 耗材：凝胶贴片可更换——卫生 + 复购，更换操作在白天完成
4. 外观：织物质感 · 莫兰迪色 · 无屏幕 · 磁吸充电 ——运动臂环，不是医疗器械
5. 交互：单按键。按一下开始，再按一下停。没别的了。
```

**底部一句**：

> 把复杂留给电路和算法。把简单留给凌晨三点迷迷糊糊的那个妈妈。

## 逐字稿

> 这页讲产品怎么做出来。
>
> 我们做了五个关键设计决策。
>
> **第一个决策：为什么是臂环，不是贴片。** 贴片需要用户自己找天泉穴。天泉穴在上臂内侧，腋前纹头下两寸，肱二头肌两个头之间。个体差异大，搞不好就贴歪了，贴歪了就无效。更致命的是：凌晨三点，迷迷糊糊，她哪有这个精力翻说明书找穴位？臂环式不一样——套上去就行。用户只要能分清上臂，就能用。我们当时的原则很简单：任何需要用户精准操作的设计，在这个场景里都是坏的设计。
>
> **第二个决策：怎么找到天泉穴？用多触点自动寻优。** 臂环内侧放六到八个电极位点，覆盖天泉穴上下各三厘米的整个区域。戴上之后，MCU 控制模拟开关轮询所有电极对，做阻抗扫描，自动选皮肤接触阻抗最低的两点作为刺激点。这个方案比物理定位标记贵几块钱 BOM——但省下了用户的学习成本、客服电话、退货和差评。这钱花得值。
>
> **第三个决策：耗材怎么处理？硬件加可更换凝胶贴片。** 臂环本身是耐用品，内侧接触皮肤的凝胶贴片是可更换的。每周换一次，卫生，也能多人共用。商业上，硬件有合理利润，贴片有复购收入。但关键设计原则是——更换贴片的操作只发生在白天。晚上戴上，仍然是套上去按开始，不需要折腾。
>
> **第四个决策：外观像什么？运动臂环，不是医疗器械。** 织物质感，莫兰迪色系，无屏幕或者隐藏式 LED 灯带，磁吸充电。产后妈妈最不需要的就是又一件提醒自己"在治病"的东西。让它像一个睡眠追踪器、孕期监测仪一样进入她的生活，放在床头柜上不突兀。
>
> **第五个决策：交互多复杂？就一个按键。** 按一下开始，再按一下停止。默认程序二十分钟，到时间自己停。没有屏幕，没有菜单，没有模式选择。她需要的是通，不是一个需要学半天的设备。
>
> 这五个决策背后是同一个原则：**把复杂留给电路和算法，把简单留给凌晨三点迷迷糊糊的那个妈妈。**

## 方案细节（备用，不一定要放在PPT上）

| 决策点 | 选了什么 | 淘汰了什么 | 理由 |
|------|------|------|------|
| 形态 | 臂环式 | 贴片式 | 套上就行，不需要找穴位 |
| 穴位定位 | 多触点阻抗自动寻优 | 物理标记、大面积覆盖、用户对照图示 | 加几块钱BOM换体验护城河 |
| 耗材 | 臂环 + 可更换凝胶贴片 | 纯硬件无耗材、纯贴片式 | 卫生 + 复购，更换操作在白天 |
| 外观 | 运动臂环/智能穿戴风 | 医疗器械风 | 去病耻感，像睡眠追踪器 |
| 交互 | 单按键 | 屏幕+菜单+多模式 | 她只需要"通"，不需要学习 |
