## 三、RGB-dTOF 融合技术栈深入

### 3.1 dTOF 物理原理（与 iTOF 对比复习）

| 维度    | dTOF (direct)              | iTOF (indirect)        |
| ----- | -------------------------- | ---------------------- |
| 原理    | 发射脉冲→SPAD接收→TDC计时→直接算距离    | 发射调制光→探测相位差→反算距离       |
| 核心器件  | VCSEL/SPAD阵列 + TDC + TCSPC | VCSEL + CMOS传感器 + 调制电路 |
| 距离精度  | **不随距离衰减**（物理限制是TDC时间分辨率）  | 随距离增大而降低（相位模糊）         |
| 抗多机干扰 | 强（时间门控，脉冲编码）               | 弱（调制频率相同会串扰）           |
| 抗阳光   | 强（SPAD单光子灵敏度 + 时间门控可滤除背景光） | 较弱（连续波调制，阳光是宽带噪声）      |
| 功耗    | 低（稀疏脉冲发射）                  | 较高（连续调制发射）             |
| 分辨率   | 较低（SPAD阵列目前Q-VGA级别）        | 较高（VGA级CMOS成熟）         |
| 成本    | 较高（SPAD+TDC工艺）             | 较低（CMOS工艺成熟）           |

**蓝芯为什么用 dTOF 做 S 系列避障**：42m远距离 + 100kLux 抗阳光 = iTOF 做不到。iTOF 在远距离+强光下信噪比崩掉，有相位模糊。

### 3.2 RGB-dTOF 融合的核心挑战

```
物理现实：dTOF 传感器（240×160）和 RGB 相机（1920×1080）
是两个分辨率相差巨大的异构传感器，且光轴不重合。
```

| 挑战         | 具体问题                                    | 解决方向                                        |
| ---------- | --------------------------------------- | ------------------------------------------- |
| **空间对齐**   | 两个传感器光心不在同一位置，视差导致对应像素的3D投影不重合          | 外参标定（R_T, t_T）+ dTOF到RGB坐标系的投影变换            |
| **分辨率鸿沟**  | dTOF只有240×160的稀疏深度点，RGB是1080p           | 深度上采样/深度补全（DEPTHOR等方法）                      |
| **时间同步**   | dTOF帧率10fps，RGB帧率15-20fps，不同步           | 硬件触发同步或软同步+时间戳对齐                            |
| **材质反射差异** | 同一场景中不同材质对940nm红外反射率不同，dTOF可能在某些材质上丢失深度 | 利用RGB纹理信息补全（语义指导）+ 多脉冲累积                    |
| **强光串扰**   | 100kLux下，阳光中的940nm分量会叠加在dTOF信号上         | 时间门控 + 窄带滤光片（940nm为中心，FWHM几十nm）+ SPAD单光子灵敏度 |

### 3.3 dToF → RGB 投影变换（公式级别掌握）

**你应该能讲清楚这个过程：**

```
步骤1：dToF 像素坐标 → dToF 3D坐标
  X_dToF = (u - c_x) * Z / f_x
  Y_dToF = (v - c_y) * Z / f_y
  Z_dToF = 深度测量值

步骤2：dToF 3D坐标 → RGB 相机 3D坐标（外参变换）
  P_RGB = R · P_dToF + t
  （R是3x3旋转矩阵，t是3x1平移向量）

步骤3：RGB 3D坐标 → RGB 像素坐标（内参投影）
  u_RGB = f_x_RGB * X_RGB / Z_RGB + c_x_RGB
  v_RGB = f_y_RGB * Y_RGB / Z_RGB + c_y_RGB

步骤4：深度值分配
  每个dToF深度点投影到RGB图像的对应像素位置
  形成稀疏深度图（240×160 → 稀疏分布在1920×1080平面上）
```

**关键：标定误差的容忍度。** dToF 像素的 iFoV（瞬时视场角）通常比 RGB 像素大得多，所以投影后的深度点在 RGB 图像上不一定落到"正确"的 RGB 像素。这就是为什么 DEPTHOR 论文把问题从"深度超分辨率"重新定义为"深度补全"。

### 3.4 蓝芯的标定专利（可聊的切入点）

蓝芯 2023.12 申请的 RGB-D 标定专利（CN120219499A）的关键创新：

- **内参标定**：只用**单张**全幅特征点标定板图像 → 降低标定复杂度
- **外参标定**：RGB与深度传感器的六自由度位姿关系
- **深度标定**：深度传感器的测量误差标定
- **一体化标定**：将三者整合为统一流程

**你可以说的**：
"我在亿维瑞光做五线雷达时，也搭建过从TXRX耦合到整机点云的标定体系。转镜倾角标定、FOV验证、距离靶标精度测试、强光模拟环境下的冗余测试——这些是分层的。看了你们的专利，你们把内参/外参/深度三件事做了一体化，这解决了量产一致性的问题。我很好奇在产线上是怎么保证 SPAD 阵列的坏点检测和补偿的。"

### 3.5 RGB-dTOF 融合在机器人场景中的实际价值

| 场景     | 纯激光雷达的痛点            | RGB-dTOF 融合的价值                         |
| ------ | ------------------- | -------------------------------------- |
| 低矮障碍物  | 单线/少线激光有盲区          | dTOF 3D点云+RGB语义 → 识别低矮障碍物的类别           |
| 悬空障碍物  | 激光只扫一个平面，可能从障碍物下方穿过 | 3D 点云直接包络 + RGB 确认                     |
| 玻璃门/镜面 | 激光穿透或反射，测不到         | RGB 看到玻璃门的存在 + TOF 虽然测不准但点云分布异常可作为判断依据 |
| 强光直射   | TOF 信噪比下降           | RGB 的高动态范围 + dTOF 的时间门控双重保障            |
| 动态行人   | 多帧点云可能丢失目标          | RGB 的物体检测跟踪 + dTOF 距离确认                |

### 4.2 对标定方案的展示锚点

你说你在亿维瑞光做了七层标定（TXRX准直→转镜倾角→FOV→点云分布→距离靶标→强光→极端场景）。蓝芯的专利在做一体化标定。这是一个完美的技术对接点：

**从"你的经验" → "他们的痛点"的对话流：**

1. "我们在小团队做标定时，每一层都得手工搭建——因为没量产压力"（这是你的故事）
2. "但你们不一样，出货数万台，标定必须在产线上自动化"（这是他们的刚需）
3. "你们的一体化标定专利把内参外参深度合并——这解决了量产中最大的一致性瓶颈"（展示你读过他们的专利）
4. "我很想了解SPAD阵列的坏点标定在产线上是怎么处理的"（一个高质量的反问）

### 4.3 如果面试官是徐永奎（TOF标定专家）

他极大概率会问：

- "你怎么做 TOF 深度标定的？误差来源有哪些？"
- "SPAD 死区/坏点怎么检测和补偿？"
- "dTOF 和 RGB 之间的外参标定误差对最终融合精度的影响有多大？"

你的回答锚点：

- 你在亿维瑞光做了整机级和模组级的标定，虽然用的是转镜方案而非全固态，但标定的分层思想是一致的
- 你知道误差来源：器件制造公差→装配公差→温漂→时漂，每个层级需要不同的标定策略
- 你对蓝芯的一体化标定专利有基本了解，能讨论产线化的思路
