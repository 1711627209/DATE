## 一、一道菜战略（餐饮行业专用）

### 餐饮行业天生分化为王
顾客选餐厅先问两个问题：
1. **吃什么？** → 招牌菜（你有没有招牌菜？我能不能记住你？）
2. **去哪吃？** → 品牌/位置

### 一道菜战略的三个部分

| 层级 | 内容 | 作用 |
|------|------|------|
| **① 招牌菜** | 突破口，聚焦 | 定海神针 |
| **② 菜单结构** | 君臣佐使：定位菜/推荐菜/爆款菜/体验菜 | 围绕招牌菜配置 |
| **③ 全流程体验** | 门店/公关/广告/上菜仪式/信任状升级 | 闭环验证 |

### 费大厨辣椒炒肉：九年穿越周期的完整样本

选辣椒炒肉四个理由：
1. **心智资源：** 本地调研1000份，辣椒炒肉代表湖南菜排第一
2. **国民菜：** 大众点评美团国民级菜品排名前列
3. **历史数据：** 长期占据销量排行榜好评第一
4. **基本款极致化：** 类似优衣库策略

发展节奏：
| 年份 | 关键动作 |
|------|---------|
| 2018 | 20+家店，长沙起家 |
| 2019 | 定定位 |
| 2020 | 战略落地 |
| 2021 | 北上深圳 |
| 2023 | 广州开店成功 |
| 2024 | 国民炒菜第一 |
| 2025 | 有机食材升级 |
| 2026 | 美国首店，启动全球化 |

> 短期靠进店率，长期靠复购率。

## 二、营销一体性

### 蓝格格的完整脉络
```
品类名（草原酸奶）
  → 品牌（蓝格格）
  → 视觉（蓝色+草原）
  → 口号（草原人民喜爱的草原酸奶）
  → 音乐（蒙古族乐队）
  → 终端试吃（五步法）
  → 产品线
  → 原点市场（郑州）
  → 传播
```
整个脉络都指向同一个点——"草原酸奶"。

> **"营销不是做的越多越好，而是做到适合和到位。"** 多余的动作又花钱又费钱又没一体性，是减分不是加分。

## 三、渠道匹配与媒体选择

### 分众三大媒体产品的差异化定位

| 媒体类型 | 场景 | 人群 | 适用阶段 |
|---------|------|------|---------|
| 电梯电视（横屏） | 写字楼 | 一二三线白领 | 新品打爆、新品牌引爆 |
| 电梯智能屏（竖屏"户外抖音"） | 社区/电梯等候间 | 日常居民 | 老产品延续、日常巩固 |
| 电梯海报 | 住宅电梯箱 | 四五线城市居民 | 深度信息传达、渠道引流 |

**选择逻辑：** 品牌生命周期与人群浓度的匹配——新品打爆选电梯电视，日常维护选电梯智能屏，下沉渗透选电梯海报。

### 从"四高"到"四可"：投放策略升级

| 旧范式 | 新范式 | 驱动因素 |
|--------|--------|---------|
| 高触达 | 可精准 | 阿里150亿投资（2018年） |
| 高频次 | 可归因 | 数字化道路开启 |
| 高完播 | 可互动 | 天工数据平台接入 |
| 高覆盖 | 可优化 | 三大电商平台数据打通 |

### 投放归因链路
- **投前：** 天猫200+APP人群数据 + 线下楼宇信息 → 精准匹配
- **投中：** 云端5分钟快速上刊 + AIPL人群包放入客户电商平台数据银行
- **投后：** 阿里/百度/微信搜索指数增长 → 评估体系闭环

## 四、AIPL可归因模型

### 美妆品牌8周分众投放案例
某线上新品牌2023年首次与分众合作，8周大曝光投放占预算90%+：

| 指标 | 数值 |
|------|------|
| 百度指数增长 | >200% |
| 小红书搜索指数增长 | >100% |
| 双十一预售排名 | 美妆类别第一 |
| AIPL新增A人群 | 5130万 |
| 贡献销售额 | 约2.6亿（客单价300元） |
| 独立ROI | 6.4 |

### AIPL四部人群定义
| 阶段 | 含义 | 指标 |
|------|------|------|
| **A** (Aware) | 知道/曝光人群 | 看过广告+进入店铺 |
| **I** (Interest) | 兴趣人群 | 关注/收藏/加购 |
| **P** (Purchase) | 购买人群 | 完成交易 |
| **L** (Loyalty) | 忠诚人群 | 二次回购 |

## 五、支付宝"碰一下"六种互动玩法

| 玩法 | 案例 | 核心数据 |
|------|------|---------|
| 新品试用 | 蒙牛白奶 | 一周14万人参与，拉新4万+会员 |
| 游戏化互动 | - | 参与约40万，门店引流核销率超10% |
| 引流即时零售 | 淘宝闪购 | 核销率40%，新客占比超70% |
| 餐饮到店团购 | 麦当劳0元咖啡 | 核销率约27% |
| 留资引流 | 4S店/体检机构 | 碰一下→抽奖→留资→到店 |
| 数字皮肤引爆 | 新代言人 | 碰一下更换手机头像/壁纸 |

**底层逻辑：** 分众物理场景 + 支付宝即时支付 = 从"被动看广告"变为"主动参与"

## 六、品牌投放执行清单

### 投放前
- [ ] 定位是否清晰？一句话能说清楚吗？
- [ ] 差异点是否攻击了对手弱势？
- [ ] 命名和视觉是否协同？
- [ ] 渠道选择是否与品牌阶段匹配？

### 投放中
- [ ] 是否追踪AIPL人群变化？
- [ ] 搜索指数是否监测？
- [ ] 是否可以快速上刊调整？

### 投放后
- [ ] ROI是否可归因？
- [ ] 是否形成可复制的增长模式？
- [ ] 下一步是延续还是升级？
