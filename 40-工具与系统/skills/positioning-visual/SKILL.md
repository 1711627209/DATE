# 视觉品牌 Skill（positioning-visual）

> 来源：2026-08-29 林和西横路163号 7(1) 李里斯咨询集团课程
> 核心原则：视觉是全球通用的语言，0.25秒即可建立记忆。

---

## 视觉锤 vs Logo

| | Logo | 视觉锤 |
|---|------|--------|
| 定义 | 徽标/商标缩写 | 品类或定位的视觉化表达 |
| 关系 | 是品牌标识 | 可以是Logo，也可以不是 |
| 目的 | 法律注册保护 | 进入消费者心智 |

**关键区分：** Logo不一定是视觉锤，但视觉锤一定是能进入心智的视觉资产。

---

## 视觉锤十大来源

| 来源 | 案例 | 说明 |
|------|------|------|
| **形状** | 兰博基尼（公牛/骏马）、耐克钩子 | 具象可描述，一眼认出 |
| **颜色** | 麦当劳黄、肯德基红、蒂芙尼蓝 | 单一颜色优于多色，建立颜色资产 |
| **产品包装** | 瓦片雪糕、小罐茶、绝对伏特加 | 开箱即用，零售场景强 |
| **动态** | 橙汁吸管造型 | 动态>静态，记忆更深刻 |
| **符号** | 联想小红点、爱马仕橙色盒子 | 失去原始意义后成为独特标识 |
| **明星代言** | 瓜子（孙红雷）vs 优信（外国巨星失败） | 双刃剑，需考虑会老化问题 |
| **动物人格化** | 京东狗、天猫猫、美团小黄人 | 互联网公司普遍做法 |
| **白描传承画面** | 南方黑芝麻糊 | 情感共鸣，跨越代际 |
| **场景视觉** | 瑞幸鹿标无处不在 | 从门头到杯身到APP，全触点覆盖 |
| **创始人** | 需谨慎 | 考虑会老化问题 |

## 成功视觉的判断标准

> **能用语言直接描述出来 = 成功**
> **难以用语言描述 = 失败**

### 成功案例

| 品牌 | 描述方式 | 成功要素 |
|------|---------|---------|
| 麦当劳 | "金色的M形拱门" | 简单形状+标志性颜色 |
| 兰博基尼 | "一头公牛" | 具象动物，文化关联强 |
| 瑞幸 | "一只鹿站在咖啡杯旁" | 场景化视觉，可描述 |
| 加拿大鹅 | "加拿大地图轮廓" | 国家符号，具象可描述 |
| 优耐陆 | "轮胎里的红雨伞" | 意外元素，差异化强 |

### 失败案例

| 品牌 | 问题 | 后果 |
|------|------|------|
| 极狐 | 抽象图形，无法描述 | 传播困难 |
| 哪吒汽车 | 抽象线条，看不懂 | 认知混乱 |
| 理想汽车 | 抽象几何，难描述 | 传播成本高 |
| 波士登 | 抽象设计，无法用语言描述 | 传播受阻 |
| 大多数中国品牌的详情页视觉 | 过于隐晦，抽象 | 品牌感知弱 |

## 瑞幸视觉应用：教科书级案例

瑞幸鹿标无处不在：
- 门头 → 店内 → 杯身 → 外卖袋 → APP → everywhere

**对比：** 很多品牌说"视觉设计太大门头挂不下"——瑞幸的做法是门头挂不下就挂店里面，杯子上也有。

**心理影响：** 消费者甚至能在星巴克和瑞幸之间产生"招待客户用星巴克low了"的心理落差，说明视觉直接影响了品牌感知。

## 中国品牌视觉机会窗口

> "中国品牌对视觉的应用普遍过于隐晦——这是一个巨大机会窗口。"

**现状诊断：**
- 大多数品牌视觉=抽象Logo放官网，没有系统性视觉锤
- 品牌详情页视觉隐晦，消费者看不懂
- 视觉没有穿透到产品包装、门店、线上触点

**行动建议：**
1. 先用一句话描述你的视觉锤（说不出来=需要重做）
2. 检查视觉是否在所有触点一致出现（门头/包装/线上/线下）
3. 考虑颜色资产（单一颜色是否能成为品牌符号）

## 命名与视觉协同

好名字+好视觉=品牌感质变。

**魏春磊案例：**
- 原名"味之美"火锅底料 → 改名"熊猫王子"+配套熊猫视觉
- 结果：名字好记（熊猫+王子），视觉独特，品牌感立刻提升
- 发布会上改名前后对比，品牌感明显不同，终端营销也好做了

**核心原则：**
- 命名是传播基础（说出口）
- 视觉是记忆抓手（看得见）
- 两者必须协同，不能割裂

## 视觉诊断清单

- [ ] 你的视觉能在一句话内描述清楚吗？
- [ ] 消费者0.25秒内能认出你的视觉吗？
- [ ] 视觉在门头/包装/线上/线下是否一致？
- [ ] 有没有建立颜色资产（单一颜色识别）？
- [ ] 和竞品视觉对比，差异化够不够？
- [ ] 视觉是否支撑了命名传达的定位？
