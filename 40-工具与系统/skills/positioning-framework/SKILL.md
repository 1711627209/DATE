# 定位框架 Skill（positioning-framework）

> 来源：2026-08-29 林和西横路163号 李里斯咨询集团课程（7场，共约10小时）
> 适用对象：创业者、产品负责人、市场决策者

## 核心哲学

**品牌不是做出来的，是选出来的。** 战略的本质是选择——选择在哪里打、选择不对抗什么、选择不做什么。定位理论的核心公式：

> **要么成为现有品类数一数二，要么开创全新品类自动成为领导者。**

## 第一章：心智七法则（底层操作系统）

消费者心智有七大运行规律，是品牌战略的根本依据：

| 法则 | 核心机制 | 商业启示 |
|------|---------|---------|
| ① 优先分类过滤 | 新信息先归类再记忆，无法归类直接排斥 | 命名要易懂，不要云里雾里 |
| ② 容量有限 | 同一品类通常记住≤7个品牌，风险越低越少 | 传播卖点不超过3个 |
| ③ 厌恶混乱 | 大脑天生惰性，复杂信息标记为混乱 | 多就是少，极度简化 |
| ④ 缺乏安全感 | 面临五类风险通过从众和寻求证明降低决策成本 | 主动亮出领导者身份 |
| ⑤ 不易改变 | 锚定效应显著，初始认知长期影响判断 | 负面认知无法扭转时启用新品牌 |
| ⑥ 易失焦点 | 品牌延伸产生跷跷板效应 | 品牌力量与产品数量成反比 |
| ⑦ 存同存异 | 对同质化信息过滤，对新品类关注度高 | 差异化胜过更好 |

### 法则① 优先分类过滤（完整论述）
消费者接触新信息时第一反应不是记忆，而是根据既有认知进行分类。如果无法归类，信息会被直接过滤排斥——"你不知道是什么，通常不予记忆，直接清除掉"。逻辑学中的归纳法支撑了这一行为：人类用经验归纳生存，不会接受复杂概念。心智如同分类箱，有多个小格子，每个格子只记住品类代表品牌。

**案例：崂山白花蛇草水**
- 原材料命名（白花蛇舌草）→ 消费者无法归类 → 卖50年仍亏损
- 正确思路：草本气泡水（在已有品类"气泡水"中分化新品类）

**案例：千禾零添加酱油**
- 传统酱油市场已被海天/李锦记/厨邦占据
- 开创"零添加酱油"品类 → 自动成为领导者 → 迅速突破30亿

### 法则② 容量有限（完整论述）
心智容量极其有限——通常记住的品牌不超过7个。决策风险越低记住的品牌越少（垃圾袋品牌？说不出几个），决策风险越高记住的品牌越多（手机能说五六个）。七法则：七个品牌通常占到90%左右的市场份额，十名开外品牌经营举步维艰。

### 法则③ 厌恶混乱（完整论述）
大脑天生惰性，会将复杂信息标记为混乱，不愿花费时间梳理冗余信息。"多就是少"——信息越多，进入心智的越少。企业喜欢瑞士军刀思维（功能齐全但每件都不专业），映射到商业：叠加卖点（吸力大+噪音小+外观好看+易清洗），但心智厌恶复杂。费大厨聚焦辣椒炒肉单一招牌菜，通过光环效应带动全店其他菜品销售。

### 法则④ 缺乏安全感（完整论述）
消费者决策面临五类风险：金钱、功能、生理、社会、心理。应对不安全感的方式是从众和寻求证明。长城皮卡连续27年中国销量第一即利用这一心理。品牌领导者要主动亮出领导者身份，给消费者"选我肯定没错"的决策理由。

### 法则⑤ 不易改变（完整论述）
消费者对品牌的初始认知会长期影响后续判断，即便事实不符也难以扭转。BBA新能源被调侃为"杂牌电车"，但从来没人怀疑BBA燃油车是杂牌——同一事实，认知不同。比亚迪在燃油车时代落后反而成为新能源时代的优势（无包袱、果断全部转向）。启示：负面认知无法扭转时，应启用新品牌切入新品类而非强行纠正。

### 法则⑥ 易失焦点（完整论述）
海信案例：开创中国第一台变频空调却被美的反超。海信同时推电视和空调，认知焦点在两者间摇摆（跷跷板效应），最终两个都没打透。美的聚焦变频空调战略传播（"买变频，选美的"），后来居上。"品牌的力量与所代表的产品数量成反比"——短期增加SKU有利，长期必然稀释品牌资产。

### 法则⑦ 存同存异（完整论述）
用户对同质化信息会直接过滤，对全新品类、差异化定位的关注度远高于所谓的"更好的产品"。所有品牌动作需顺应用户既有认知，不可试图教育用户扭转固有认知。

## 第二章：二元法则与竞争定位

### 二元法则（完整论述）
一个成熟品类中，前七名品牌通常占据90%左右市场份额和利润。可口可乐vs百事可乐、奔驰vs宝马、肯德基vs麦当劳——二元法则无处不在。领导者的对立面通常孕育第二个机会："奔驰发明汽车，传播乘坐舒适→天然驾驶性弱→宝马做驾驶性"。

**中国演化案例：**
- 新能源车：2014年七八十个品牌 → 2024年剩二三十个，还在继续淘汰
- 手机：从数十个品牌收敛到五六个

### 攻击对手强势背后的弱势
千禾案例：广告语"千禾零添加，天然好味道"攻击的是竞争对手的强势（好吃），不是弱势。有添加酱油的强势就是味道好，你应该攻击的是"有添加的有害健康"这个弱势。修改定位为"绝不添加色素、味精、防腐剂"——直接说就是海天、李锦记、厨邦。导入新定位后迅速突破30亿。

**核心原则：起点一致、方向相反，才能转化对手生意。**

## 第三章：品类创新四步法

```
开创 → 定义 → 推出 → 主导
  ↓      ↓      ↓      ↓
心智/   简洁    原点    信任状
市场/    清晰    人群    持续升级
技术     命名    市场    （企标→行标→国标）
洞察     命名    场景
```

### 新品类机会三大来源（优先级排序）
| 优先级 | 来源 | 特点 |
|-------|------|------|
| ① 心智洞察 | 消费者心智中的空白机会 | 门槛最低，最多企业可做 |
| ② 市场洞察 | 行业趋势和规模变化 | 有趋势但可能已有人做 |
| ③ 技术洞察 | 新技术带来的可能性 | 最难但壁垒最高 |

### 品类创新三步法
1. **分析品类**：以史为镜，研究品类的分化路径；判断消费者心智中关键的分化标准；分析高阶市场的品类发展历史（欧美日韩是中国的高阶市场）
2. **判断分化标准**：价格带是第一分化标准——切错了价格带，剩下所有努力都没有用
3. **参考高阶市场**：用历史经验规避重复错误

### 真品类 vs 伪品类
检验标准：通过企业教育传播之后，消费者会不会形成相应的思考模式、会不会这样来表达？
- "白家电"教育了三十年，没有消费者会说"我要买一个白家电" → 伪品类
- "零糖气泡水"一说消费者立刻理解 → 真品类

### 进化 ≠ 分化
福特从轿车分化出SUV是分化（不同），2026款改2027款是进化（更好）。拼参数、拼价格、没有摆脱内卷的都是进化不是分化。

### 品类选择三角
三个维度交集才是战略机会：
- 品类在趋势上要有成长性
- 竞争上要占比（对手没有牢牢绑定）
- 自身上要有能力把握

## 第四章：中小企业战略五步法

1. **分析品类** → 研究分化路径 + 判断分化标准 + 参考高阶市场
2. **找到心智空白** → 心智洞察 > 市场洞察 > 技术洞察
3. **定义差异化定位** → 攻击对手强势背后的弱势
4. **验证样板市场** → 价值验证 + 增长验证
5. **滚雪球式扩张** → 方向一致，逐个推进

### 中小企业五大认知误区
| 误区 | 表现 | 后果 |
|------|------|------|
| 忽视战略，忙于战术 | 身累心累，瞎打乱打 | 资源分散，没有焦点 |
| 战略不自信 | 越小的企业越不敢做战略 | 被大企业压制，丧失差异化 |
| 打法乱套 | 跟行业内领先品牌学 | 整个节奏被带偏 |
| 太爱学习，学成四不像 | 把很多有效方法组合到自己身上 | 每一招都没有成为杀手锏 |
| 不会选对手 | 营销上大多数人没思考 | 这是你的机会，但你没有抓住 |

### 战略即取舍
老板电器案例：调研显示消费者买油烟机第一关注吸排效果，第二易清洗，第三外观，第四噪音。但企业往往既传播吸力大又传播噪音小又传播外观好看又传播易清洗，试图占完所有好处，结果一个也占不打。大吸力必然噪音大——这是物理取舍。

### 不要卷价格
"如果你行业里所有友商都在卷低价，你就一定往高价走。"价格和认知出了问题，本质是你不值那个钱。一旦踏上卷价格这条路，没有回头路。

## 第五章：决策清单（快速诊断）

当用户提出品牌/产品问题时，按以下顺序诊断：

### 第一层：心智分类检查
- [ ] 产品名称/品类名，消费者3秒内能否理解是什么？
- [ ] 如果不能，改名还是重做定位？
- [ ] 当前品类中，品牌处于前7名还是10名开外？

### 第二层：差异化检查
- [ ] 和竞争对手相比，差异点在哪里？
- [ ] 这个差异点是攻击对手强势背后的弱势吗？
- [ ] 还是只是在说"我更好"（同质化信息，会被过滤）？

### 第三层：聚焦检查
- [ ] 当前品牌代表几个产品/品类？
- [ ] 是否有跷跷板效应（认知焦点摇摆）？
- [ ] 传播卖点是否超过3个？

### 第四层：品类选择检查
- [ ] 是在已有品类里竞争，还是在开创新品类？
- [ ] 如果是新品类，价格带/人群/场景的分化标准是什么？
- [ ] 是真品类还是伪品类？

### 第五层：执行检查
- [ ] 营销动作是否一体性（每一处都指向同一个点）？
- [ ] 定价策略是否与定位匹配（卖得更贵还是更便宜）？
