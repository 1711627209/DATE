# 抖音实时热榜抓取器

## 这个工具能做什么

一条命令拉取抖音当前热搜排行榜,自动格式化为带热度值、链接和封面图的可读列表。

**能获取到的信息：**

| 数据项 | 说明 |
|--------|------|
| 热点标题 | 每条热搜的核心内容 |
| 热度指数 | 以万为单位的易读数值 |
| 跳转链接 | 可直接访问的抖音搜索页 URL |
| 封面图 | 部分热点附带的缩略图（非全部） |
| 榜单标签 | 爆 / 热 / 新 / 荐 等分类标识 |
| 内容类型 | 视频、音乐、挑战赛等 |

**怎么触发：**

直接用自然语言说就行：
- "帮我看看抖音今天热搜"
- "抖音热榜前10是什么"
- "现在抖音在热什么"
- "给我抖音热点"

## 怎么用

**前提：** 确定此 SKILL.md 所在目录为 `SKILL_DIR`，脚本完整路径为 `${SKILL_DIR}/scripts/douyin.js`。

**拉取完整热榜（默认 50 条）：**
```bash
node ${SKILL_DIR}/scripts/douyin.js hot
```

**只看前 N 条：**
```bash
node ${SKILL_DIR}/scripts/douyin.js hot 10
```


链接为纯文本 URL,可直接复制打开,无 HTML 标签。

## 接口返回字段

| 字段 | 类型 | 含义 |
|------|------|------|
| rank | number | 排名序号（从 1 开始） |
| title | string | 热搜标题 |
| popularity | number | 热度数值（HotValue,解析失败时为 0） |
| link | string | 详情页链接 |
| **cover** | **string \| null** | **封面缩略图 URL（v1.1.0 新增,部分为空）** |
| label | string \| null | 榜单标签（爆/热/新/荐等） |
| type | string | 内容品类（视频/音乐/挑战赛等） |

## 🚧 工具使用边界

**✅ 适用场景（推荐）：**
- 个人内容创作参考：了解当日热点，辅助选题策划
- 社交媒体运营参考：追踪热点趋势，制定内容方向
- 学习研究用途：分析热榜规律、数据结构研究
- 低频个人使用：每日查询次数建议不超过 10 次

**❌ 禁止场景（超出边界）：**
- 高频自动化抓取（每小时多次或 7×24 小时持续运行）
- 将抓取数据进行商业转售或对外提供数据服务
- 批量下载、镜像或二次分发抖音平台内容
- 用于训练商业 AI 模型或构建竞品数据库
- 任何可能对抖音服务器造成异常负载的行为

**⚙️ Telegram 定时推送配置（cron-job.js）：**
使用定时推送功能前，需配置 `TELEGRAM_CHAT_ID` 环境变量（你的 Telegram 用户 ID 或频道 ID）。
