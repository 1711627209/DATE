# 作业3：车载/低速激光雷达行业竞品分析报告模板

## 题目

面向 `车载/低速激光雷达行业` 输出一份行业竞品分析报告，建立产品经理业务思维。

---

## 一、报告目标

这份报告的目的不是简单罗列竞品参数，而是通过对行业和竞品的分析，回答以下几个问题：

- 这个行业为什么值得做？
- 行业当前最核心的竞争点是什么？
- 不同竞品分别在打什么场景、什么定位、什么技术路线？
- 低速线和高端线的打法有什么不同？
- 我们自己的 `5线` 和 `196线` 应该怎么定位？
- 我们应该优先做什么，不应该做什么？

---

## 二、行业定义

### 1. 行业边界

本次分析聚焦：

- 车载激光雷达
- 低速激光雷达
- 面向电动车、园区车、低速汽车、特种车辆等场景
- 重点看车载前装和低速近场补盲，不展开到工业测量、安防、清洁机器人等泛传感器行业
- 讨论重点不是“有没有激光雷达”，而是“在什么场景下能稳定量产、能否控制成本、能否快速交付”

### 2. 场景拆分

建议先把行业拆成两类场景，再看竞品差异：

- **前向长距场景**：高速领航、城市领航，关注远距离识别、夜间和逆光稳定性
- **近场低速场景**：泊车、盲区补盲、低速会车、园区通行，关注近距离稳定探测、视场角和成本
- **量产交付场景**：OEM / Tier1 导入、车规验证、批量一致性和供货稳定性

### 2. 分析对象建议

建议分成两条线来理解：

- **低端验证线**：`5线激光雷达`
- **高端车规线**：`196线激光雷达`
- `5线` 更适合表达低成本验证、核心器件验证和低速场景适配
- `196线` 更适合表达高端车载、车规能力和前装量产能力

## 三、竞品分层

### 1. 直接竞品

直接做车载 / 低速激光雷达的产品线。

### 2. 替代竞品

虽然不是完全同类产品，但能覆盖相似场景或替代部分功能的方案。

### 3. 对标竞品

技术路线、商业化模式、客户渗透率、量产能力值得参考的产品或公司。

### 4. 竞品名单建议

建议优先选这 4 家，覆盖不同打法，便于做出层次对比：

- **禾赛 Hesai**：`AT128` 为代表，偏前装量产和车规落地，适合看成本控制、交付节奏和规模化能力
- **速腾聚创 RoboSense**：`M2`、`E1` 为代表，既覆盖车载前装，也覆盖低速近场补盲，适合看场景覆盖和平台化能力
- **Innoviz**：`InnovizTwo` 为代表，偏国际 OEM / Tier1 导入，适合看车规流程、海外交付和技术路线
- **Luminar**：`Iris`、`Halo` 为代表，偏高性能长距路线，适合看高端方案、1550nm 路线和成本压力

### 5. 竞品具体产品名称与官方定位依据

下面这部分可以直接作为正文里的“竞品选择依据”：

- **禾赛 AT128**
  - 官方定位：车规级 120° 超高清远距激光雷达
  - 官方场景：ADAS、Robotaxi、Robotrucking
  - 官方依据：官网产品页给出 `210m @10%` 探测距离、`120° x 25.4°` 视场角、`1,536,000 pts/s` 点频，并标注 `ISO 26262 ASIL B` 功能安全产品认证和 `ISO 21434` 合规开发流程
  - 官方结论：更偏车载前装和高性能远距场景

- **速腾聚创 M2 / E1**
  - 官方定位：`M2` 为 M 平台中长距车载激光雷达，`E1` 为 automotive-grade fully solid-state blind spot LiDAR
  - 官方场景：`M2` 面向智能驾驶系统升级、OEM / Tier1 量产导入；`E1` 面向盲区补盲和近场感知
  - 官方依据：官网给出 `M2 250m (200m@10%)`、`1,575,000 pts/s`，并说明 `M2` 继承 M1 Plus 的同平台与模块化设计，`M 平台` 通过 `ISO 26262 ASIL B` 功能安全认证，扫描芯片通过 `AEC-Q100` 可靠性认证；`E1` 官方页面明确写明是 `Automotive-Grade Fully Solid-State Blind Spot LiDAR`，横向 `120°`、纵向 `90°`、测距 `30m@10%`
  - 官方结论：更偏平台化迭代，兼顾前装量产和低速近场能力

- **InnovizTwo**
  - 官方定位：Next-Generation, Low-Cost, Automotive-Grade LiDAR
  - 官方场景：L2+、L3、L4 自动驾驶
  - 官方依据：官网给出 `0.3m-300m` 探测范围、`120° x 43°` 视场角、`0.05° x 0.05°` 角分辨率，并标注 `ASIL B(D)`、`ISO 26262 Compliant`
  - 官方结论：更偏车规级前装和降低成本后的规模导入

- **Luminar Iris / Halo**
  - 官方定位：Iris 为系列生产车规长距激光雷达，Halo 为下一代高量产车型方案
  - 官方场景：ADAS、高速公路自动驾驶、乘用车和商用车系列生产
  - 官方依据：官网和投资者关系材料说明 Iris 是为 automotive qualified series production 设计，`2022` 实现低量产 SOP，`2024` 实现高量产 SOP；Halo 基于同样的 `1550nm` 架构，官方给出的目标是 `4x` 性能提升、`3x` 体积缩小、`2x` 成本改善
  - 官方结论：更偏高端长距和高性能路线，但成本与供应链压力更大

## 六、报告正文结构

### 1. 行业背景

车载/低速激光雷达行业的核心价值，是为智能驾驶提供稳定的三维感知能力。它不是一个单纯比参数的赛道，而是一个把场景定义、成本控制、稳定性、交付周期和车规验证放在一起看的工程化行业。

从场景上看，这个行业主要服务三类需求：一是车载前装中的 ADAS、NOA、L2+ 和 L3；二是低速近场中的泊车、盲区补盲和低速会车；三是面向 OEM 和 Tier1 的量产导入。车载和低速之所以要放在一起看，是因为它们本质上都在解决“能不能稳定量产交付”的问题，只是前者更偏远距和高性能，后者更偏近场和低成本。

因此，评价一个激光雷达产品，不能只看点频、线数和距离，而要看它是否真正能进入整车平台，是否能在复杂天气、强光和夜间稳定工作，是否能满足车规要求并支持持续交付。

### 2. 行业核心竞争点

建议重点从五个维度判断：

- **成本**：能不能在目标价格带内落地，是否具备规模化降本能力
- **稳定性**：强光、夜间、雨雾和复杂反射场景下是否可靠
- **交付周期**：从样机到 SOP 的推进速度是否满足车厂节奏
- **量产能力**：是否具备批量一致性、供应链和制造能力
- **车规能力**：是否满足 ISO 26262、AEC-Q100、ISO 21434 等要求

一个更直接的判断是：车载激光雷达的竞争已经从“谁参数更强”转向“谁更能量产、稳定交付、适配 OEM”。其中，905nm 路线通常更利于成本下探和规模化量产，1550nm 路线通常更强调性能但成本和供应链压力更高；低速/近场场景的关键不是极限距离，而是宽视角、近距稳定和低成本。

### 3. 竞品分层分析

每个竞品都应该写成“定位 - 场景 - 为什么能卖 - 优势 - 短板 - 对应到我们的哪条线”的结构。

- **禾赛 AT128** 更偏量产型前装。它的优势是车规和交付属性强，适合主流车厂前装；短板是更偏高效量产逻辑，而不是追求最激进的性能上限。
- **速腾聚创 M2 / M1 Plus** 更偏平台化迭代。它的优势是产品线完整，既能覆盖前装升级，也能覆盖低速近场；短板是多条线并进时容易让定位边界变得复杂。
- **InnovizTwo** 更偏国际 OEM / Tier1 导入。它的优势是车规体系、低成本叙事和 L2+/L3 适配能力；短板是导入和验证周期较长，对合作方要求高。
- **Luminar Iris / Halo** 更偏高端长距。它的优势是技术上限高，强调高性能和高端车型；短板是成本和产业化压力更大。

### 4. 对比分析

把竞品放在同一个坐标系里看，可以得到比较清晰的分层：

- **高端长距路线**：Luminar 更典型，强调性能上限和高端集成
- **主流前装量产路线**：禾赛更典型，强调车规、交付和规模化
- **平台化多场景路线**：速腾聚创更典型，强调前装和低速近场共同覆盖
- **国际 OEM 导入路线**：Innoviz 更典型，强调车规体系和海外客户进入能力

如果进一步回到产品经理视角，真正的比较不是“谁更强”，而是“谁更适合什么场景”。前装量产最看重的是稳定性和交付，低速近场最看重的是成本和视场覆盖，高端长距最看重的是性能和品牌心智。

### 5. 结论

最后要落到三个结论：

- 这个行业的机会点，不在于单纯做出一个参数更高的雷达，而在于把产品真正放进整车平台，完成车规、验证、量产和交付闭环
- 行业的风险点，主要来自成本下探、车规周期、供应链稳定性和大规模交付能力
- 对我们自己的 `5线` 和 `196线` 来说，最合理的分工是：`5线` 负责低成本验证、器件验证和低速近场，`196线` 负责高端车规、前装量产和高性能长距

综合判断，这个赛道的核心不是“更远”，而是“更稳、更快交付、更适合量产”
